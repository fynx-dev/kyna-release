# AI モデルと加速設定

**設定 → AI モデル管理** でモデルのダウンロードや演算バックエンドを設定できます。

---

## 📥 モデルのダウンロードと配置

- **ワンクリックダウンロード**
  SHA-256 検証付きで安全にダウンロード。
- **保存先ディレクトリ**
  `%APPDATA%\KynaPlayer\models\`
- **手動配置**
  ネットに接続できない環境でも、`ggml-*.bin` ファイルを models フォルダに直接配置して利用可能。

---

## ⚡ ハードウェアアクセラレーションバックエンド

| バックエンド | 対象ハードウェア | 加速比 |
| :--- | :--- | :--- |
| **NVIDIA CUDA** *(推奨)* | GeForce / RTX シリーズ GPU | 🚀 最高速 (~20〜30倍) |
| **DirectML** | AMD Radeon / Intel Arc / 内蔵 GPU | ⚡ 高速 (~8〜15倍) |
| **Vulkan Compute** | 各種クロスプラットフォーム GPU | ⚡ 良好 (~8〜12倍) |
| **CPU AVX2 / OpenVINO** | 最新マルチコア CPU | 🔄 標準 (~2〜4倍) |

---

## 🧹 VRAM メモリの自動解放

- **オンデマンド読み込み**
  文字起こし実行時のみ VRAM へモデルをロード。
- **自動解放**
  処理完了後、5分間操作がない場合は自動的に VRAM を解放し、ゲームや 4K 再生のパフォーマンスを確保します。
