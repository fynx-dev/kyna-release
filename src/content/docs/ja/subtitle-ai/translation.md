# LLM 字幕翻訳

単語ごとの機械翻訳とは異なり、Kyna Player は**スライドコンテキストウィンドウ**を採用し、前後のセリフの流れを LLM に渡すことで、自然で感情豊かな翻訳を実現します。

---

## 🔌 対応翻訳エンジン

| エンジン | モデル例 | 特徴 |
| :--- | :--- | :--- |
| **DeepSeek** *(おすすめ)* | `deepseek-chat`, `deepseek-reasoner` | 圧倒的なコストパフォーマンス、自然な日本語表現 |
| **OpenAI** | `gpt-4o`, `gpt-4o-mini` | 高い多言語理解力と安定性 |
| **Anthropic Claude** | `claude-3-5-sonnet` | 表現力豊かな会話文脈の再現 |
| **Ollama (ローカル)** | `qwen2.5`, `llama3.1`, `gemma2` | 100% オフライン、無料、完全プライベート |
| **カスタム API** | OpenAI 互換のエンドポイント | プロキシや社内 API ゲートウェイ |

---

## 💬 バイリンガル字幕のレイアウト

- **上下2言語表示**
  上段に翻訳（日本語）、下段に原語（英語など）を配置。
- **翻訳のみ表示**
  映像に集中できるシンプルな字幕表示。
- **ファイル出力**
  `.srt` や `.ass` 形式で保存し、他のデバイスでも利用可能。
