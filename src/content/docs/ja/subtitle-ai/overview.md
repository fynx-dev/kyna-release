# AI 字幕機能の概要

字幕のない海外ドラマ、外国語の講義動画、ゲーム配信などを視聴する際、Kyna Player 内蔵の **AI 字幕ラボ** が威力を発揮します。

---

## ⚡ コア AI パイプライン

```
+------------------+     +--------------------+     +--------------------+     +------------------+
| 🔊 音声ストリーム | ──> | 🎙️ ローカル Whisper | ──> | 🌐 LLM 文脈翻訳    | ──> | 💬 リアルタイム   |
|  (FFmpeg 分離)   |     | (完全オフライン/安全)|     | (自然な言い回し)   |     |    バイリンガル字幕 |
+------------------+     +--------------------+     +--------------------+     +------------------+
```

---

## 🌟 主なメリット

1. **🔒 100% ローカルオフライン処理**: Whisper 音声認識はお手元の GPU（CUDA / DirectML / Vulkan）または CPU 上で直接実行されます。外部サーバーへの音声アップロードは一切行われません。
2. **🧠 文脈を考慮した高品質翻訳**: DeepSeek、OpenAI GPT-4o、Claude、ローカル Ollama と連携し、前後の会話の流れを理解した自然な字幕を生成します。
3. **⚡ 高速なタイムスタンプ自動同期**: Silero VAD により BGM や効果音をカットし、自然な発話区間ごとにタイムスタンプを正確に分割します。
