# 基本操作とキー

Kyna Player は、軽快なキーボードショートカットとマウス操作に対応しています。

---

## 🎮 主要な再生操作

| 操作 | デフォルトショートカット | マウスジェスチャー | 説明 |
| :--- | :--- | :--- | :--- |
| **再生 / 一時停止** | <kbd>Space</kbd> | 画面中央をクリック | 再生状態の切り替え |
| **停止** | <kbd>S</kbd> / <kbd>Ctrl+S</kbd> | 停止ボタン | デコードを停止し先頭へリセット |
| **フルスクリーン** | <kbd>Enter</kbd> / <kbd>F11</kbd> | 画面をダブルクリック | 全画面表示の切り替え |
| **コマ送り（進む）** | <kbd>.</kbd> / <kbd>E</kbd> | コマ送りボタン | 1フレーム進む |
| **コマ戻し（戻る）** | <kbd>,</kbd> | コマ戻しボタン | 1フレーム戻る |
| **音量アップ / ダウン** | <kbd>↑</kbd> / <kbd>↓</kbd> | ホイール上下 | 音量を ±5% 調整 |
| **ミュート切り替え** | <kbd>M</kbd> | スピーカーアイコン | 消音 / 解除 |
| **再生速度 変更** | <kbd>]</kbd> / <kbd>[</kbd> | 速度メニュー | 速度を ±0.1倍 調整 |
| **等速リセット (1.0x)** | <kbd>Backspace</kbd> / <kbd>Z</kbd> | 速度メニュー (1.0x) | 通常速度に復帰 |

---

## ⏩ シーク操作

- **小刻みシーク (±5秒)**
  <kbd>→</kbd> / <kbd>←</kbd>
- **中シーク (±30秒)**
  <kbd>Ctrl</kbd> + <kbd>→</kbd> / <kbd>←</kbd>
- **大シーク (±60秒)**
  <kbd>Shift</kbd> + <kbd>→</kbd> / <kbd>←</kbd>
- **割合ジャンプ (0%〜90%)**
  数字キー <kbd>0</kbd> 〜 <kbd>9</kbd>
