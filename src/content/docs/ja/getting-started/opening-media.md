# メディアを開く

**Kyna Player** は、多彩なメディア読み込み方法をサポートしています。ローカルの単一ファイル、シリーズ全体のフォルダ、標準 M3U プレイリスト、オンラインストリーミング URL を瞬時にロードして再生できます。

---

## 📂 1. ローカルメディアファイルを開く

### クイックアクセス
- **ショートカット**
  <kbd>O</kbd> キーを押してファイル選択ダイアログを開きます。
- **画面ボタン**
  タイトルバーメニューまたはコントロールバーの **ファイルを開く** をクリックします。
- **対応フォーマット**
  MP4, MKV, AVI, MOV, WEBM, FLV, WMV, TS, M2TS, M4V, RMVB, 3GP, VOB など、ほぼすべての主流形式に対応。

![ファイルを開くメニュー](/assets/images/docs/getting-started/openfile-menu.png)

### プレイリスト追加の挙動
**設定 → プレイリスト** で動作を設定できます：
- 🔄 **置換して再生**（デフォルト）
  現在のキューをクリアし、選択したファイルを直ちに再生します。
- ➕ **末尾に追加して再生**
  現在のリストを保持したまま、新しいファイルを末尾に追加して再生を開始します。

![プレイリスト設定](/assets/images/docs/getting-started/openfile-playlist-settings.png)

---

## 🖱️ 2. ファイル＆フォルダのドラッグ＆ドロップ

### ファイルのドロップ
Windows エクスプローラーから動画・音声ファイルを Kyna Player ウィンドウへ直接ドラッグします。

### フォルダのドロップ（一括スマートスキャン）
ドラマシリーズや音楽アルバムのフォルダをドロップすると、**フォルダ取り込み** ダイアログが表示されます：
- 🔍 **再帰的スキャン**
  「サブフォルダをスキャン」にチェックを入れると、すべての階層のメディアを自動検出します。
- 📊 **リアルタイム統計**
  スキャン進捗と検出されたファイル数を表示します。
- ⚡ **自然順ソート**
  話数順（EP01, EP02 ... EP10）に正しく自動整列されます。

![ドラッグ＆ドロップとフォルダスキャン](/assets/images/docs/getting-started/drag-files-and-folder.png)

---

## 🌐 3. ネットワーク URL ストリーミング

Kyna Player はオンラインストリームやライブ配信の直接再生に対応しています：
- **URL を開く**
  <kbd>Ctrl</kbd> + <kbd>U</kbd> キーを押します。
- **対応プロトコル**
  HTTP / HTTPS 直リンク、HLS (`.m3u8`)、RTMP、RTSP、WebDAV。

![URL を開くダイアログ](/assets/images/docs/getting-started/open-url-dialog.png)
