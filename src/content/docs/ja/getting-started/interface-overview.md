# インターフェース

Kyna Player は、映像への没入感を最大限に高める**フレームレスデザイン**を採用しています。直感的なコントロールバーとサイドパネルにより、スムーズな操作が可能です。

---

## 📐 画面構成

![インターフェース概要](/assets/images/docs/getting-started/openfile-playlist-settings.png)

Kyna Player は主に 4 つの領域で構成されています：

```
+-------------------------------------------------------------+
| 🏷️ タイトルバー (ウィンドウ操作 / 最前面固定 / メディアタイトル) |
+-------------------------------------------------------------+
|                                                             |
|                                            +--------------+ |
|                                            |              | |
|                    📺 メインビューポート      |  📑 サイド   | |
|                 (ジェスチャー / 画面調整)     |   ドロワー   | |
|                                            |              | |
|                                            +--------------+ |
+-------------------------------------------------------------+
| 🎛️ フローティングコントロールバー (シークバー / 操作ボタン / 音量) |
+-------------------------------------------------------------+
```

---

## 1. 🏷️ 上部タイトルバー

マウスをウィンドウ上部に移動すると表示されます（フルスクリーン時は自動非表示）：
- **📌 最前面に固定**
  プレイヤーを常に他のウィンドウの手前に表示します。
- **🎬 メディアタイトル**
  再生中のファイル名を表示します。
- **⚙️ ウィンドウ操作**
  最小化、最大化 / 元に戻す、閉じる。

---

## 2. 📺 メインビューポート

GPU アクセラレーションによる描画エリアで、直感的なマウス操作に対応しています：

| 操作 | 動作 |
| :--- | :--- |
| **シングルクリック** | 再生 / 一時停止の切り替え |
| **ダブルクリック** | フルスクリーン表示の切り替え |
| **マウスホイール** | 音量調整（±5%） |
| **ドラッグシーク** | 画面中央に時間とプレビュー HUD を表示 |
| **ドラッグ＆ドロップ** | ファイル、フォルダ、字幕を直接読み込み |
| **右クリック** | コンテキストメニューの表示（トラック、フィルタ、設定など） |

---

## 3. 🎛️ フローティングコントロールバー

再生に必要な主要コントロールが集約されています：
- **インタラクティブタイムライン**
  シークバー上でマウスを移動すると、サムネイルプレビューが表示されます。
- **再生ボタン群**
  前へ / 次へ (<kbd>PageUp</kbd>/<kbd>PageDown</kbd>)、再生 / 一時停止 (<kbd>Space</kbd>)、停止 (<kbd>S</kbd>)、コマ送り (<kbd>.</kbd>)。
- **音量と増幅**
  最大 200% のソフトウェア音量ブーストに対応したスライダー。
- **再生速度とループ**
  0.5倍〜2.0倍の速度切替、リピートモード（全曲、1曲、シャッフル、順次）。

---

## 4. 📑 サイドドロワー

コントロールバー右側のアイコンまたはショートカットで開きます：

| パネル名 | 説明 | ショートカット |
| :--- | :--- | :--- |
| 📑 **プレイリスト** | キューの管理、検索、フォルダ取り込み | `F3` / `Alt+P` |
| 💬 **トラックと字幕** | 音声/字幕トラック選択、デュアル字幕、外観 | `Alt+S` |
| 🤖 **AI ラボ** | Whisper 音声文字起こし、LLM 翻訳 | `Alt+A` |
| ✨ **画質向上** | Anime4K、DLSS 5、シェーダー、色調整 | `Alt+V` |
| ⚙️ **設定** | ハードウェアデコード、関連付け、言語切替 | `F2` / `Ctrl+,` |
