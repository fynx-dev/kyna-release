# 映像出力と画質設定

Kyna Player は Direct3D 11/12 による高品位なレンダリングパイプラインを搭載し、GPU の性能を最大限に引き出しながら、柔軟なアスペクト比調整、色調補正、広色域 HDR 出力を実現します。

---

## 🚀 映像出力とハードウェアアクセラレーション

**設定 → 映像とレンダリング** で最適なレンダラーを選択できます：

| 出力モード | 特徴とメリット | 推奨環境 |
| :--- | :--- | :--- |
| **Direct3D 11 (D3D11)** *(推奨)* | 高い互換性と超低遅延。GPU ゼロコピー出力に対応。 | Windows 10/11 の一般的な GPU / 内蔵 GPU |
| **Direct3D 12 (D3D12)** | 最新 GPU に最適化された低レベルレンダリング。 | 最新の独立 GPU (RTX / RX シリーズ) |
| **ソフトウェアデコード (CPU)** | 特殊なレガシー形式に対する高互換フォールバック。 | トラブルシューティング用 |

---

## 📐 アスペクト比とスケーリング

<kbd>A</kbd> キーまたは右クリックメニューの **アスペクト比** で切り替え：
- **比率を維持（フィット）** *(デフォルト)*: 元の縦横比を維持し、黒帯（レターボックス）を付加。
- **ウィンドウに合わせて拡大（ストレッチ）**
  画面いっぱいに引き伸ばして表示。
- **クロップ（画面全体を埋める）**
  比率を維持したまま余白をなくすようにトリミング拡大。
- **固定比率**
  `16:9`, `4:3`, `21:9` (ウルトラワイド), `1:1`。

---

## 🎚️ 色調補正

サイドバーの **画質パネル** でリアルタイムに調整可能：
- **明るさ / コントラスト**
  -50 〜 +50
- **彩度 / 色相**
  -50 〜 +50
- **ガンマ**
  0.5 〜 2.0
- **ワンクリックリセット**
  元の映像カラープロファイルに瞬時に復帰。

---

## 🔄 回転と反転

- **時計回りに 90° 回転**
  <kbd>Alt</kbd> + <kbd>R</kbd>
- **水平ミラー反転**
  <kbd>Alt</kbd> + <kbd>H</kbd>（ダンスの振り付け練習に最適）
- **垂直反転**
  <kbd>Alt</kbd> + <kbd>V</kbd>

---

## 🌈 HDR とトーンマッピング

4K HDR10、HLG、Dolby Vision 映像の再生時：
- **HDR パススルー**
  HDR 対応ディスプレイへネイティブ 10-bit BT.2020 信号をダイレクト出力。
- **SDR トーンマッピング**
  SDR ディスプレイでも Reinhard / Mobius アルゴリズムにより白飛びを防ぎ、鮮やかな色彩で表示。
