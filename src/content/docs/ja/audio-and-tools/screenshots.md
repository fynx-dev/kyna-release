# スクリーンショット

映画の名シーンやアニメの美しいカットを、原画サイズの高精細な画像として瞬時に保存できます。

---

## ⚡ キャプチャモードとショートカット

| 操作 | ショートカット | 説明 |
| :--- | :--- | :--- |
| **通常キャプチャ** *(おすすめ)* | <kbd>Ctrl</kbd> + <kbd>S</kbd> / <kbd>F5</kbd> | **字幕なし**の純粋な元解像度フレームを保存。 |
| **字幕付きキャプチャ** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 画面に表示されている字幕を含めてキャプチャ。 |
| **クリップボードにコピー** | <kbd>Ctrl</kbd> + <kbd>C</kbd> | 画像ファイルを作成せず、クリップボードに直接コピー。 |

---

## 📂 フォーマットと命名規則

- **画像形式**
  可逆圧縮 PNG、高品位 JPEG、WebP。
- **命名テンプレート**
  `{title}_{time}_{index}.png`（例：`Inception_01-24-36_001.png`）。
- **保存先**
  デフォルトで `%USERPROFILE%\Pictures\KynaPlayer\` に保存されます。通知トーストをクリックするとフォルダが直接開きます。
