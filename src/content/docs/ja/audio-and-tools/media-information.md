# メディア情報と診断

詳細なエンコード情報やハードウェアデコードの稼働状況を確認できます。

---

## 🔍 メディア情報の開き方

- **ショートカット**
  <kbd>Ctrl</kbd> + <kbd>I</kbd> または <kbd>Shift</kbd> + <kbd>I</kbd>
- **メニュー**
  右クリック → **ツール** → **メディア情報**

---

## 📊 詳細な診断項目

- **コンテナ情報**
  フォーマット（`.mkv`, `.mp4` など）、サイズ、全体ビットレート。
- **映像ストリーム**
  コーデック（`HEVC`, `AV1`, `H.264`）、解像度（`3840x2160`）、FPS、色空間（`BT.2020 10-bit`）、HDR 規格（`HDR10`, `Dolby Vision`）。
- **音声・字幕ストリーム**
  チャンネル数、サンプリングレート、言語情報。
- **動作診断**
  稼働中のデコーダー（`D3D11VA - NVIDIA NVDEC`）、ビットレート推移グラフ、ドロップフレームカウンター。
