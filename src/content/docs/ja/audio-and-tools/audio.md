# 音声トラックと同期

サラウンド音声のパススルー出力、複数音声トラックの切り替え、ミリ秒単位の音ズレ補正に対応しています。

---

## 🎧 音声トラックの選択

- **切り替えショートカット**
  <kbd>A</kbd> または <kbd>Ctrl</kbd> + <kbd>A</kbd>
- **詳細メタデータ**
  言語、チャンネル構成（`5.1ch`, `7.1ch`, `Stereo`）、コーデック（`DTS-HD MA`, `TrueHD Atmos`, `FLAC`, `AAC`）を表示。

---

## 🎛️ 出力デバイスとダウンミックス

- **独立出力デバイス**
  システム全体の音声を邪魔することなく、プレイヤーの音声のみを指定のヘッドホンや USB-DAC へ出力。
- **HRTF 空間ダウンミックス**
  5.1ch / 7.1ch サラウンド音源をステレオヘッドホン向けに自然にダウンミックスし、中央のセリフを明瞭化。
- **ビットストリームパススルー**
  AV アンプへ HDMI / 光デジタル経由で未加工の音声を直接出力。

---

## ⏱️ 音ズレ同期補正

| 操作 | ショートカット | 説明 |
| :--- | :--- | :--- |
| **音声を 100ms 遅らせる** | <kbd>Ctrl</kbd> + <kbd>]</kbd> | 映像より音声が先に出る場合 |
| **音声を 100ms 早める** | <kbd>Ctrl</kbd> + <kbd>[</kbd> | 音声より映像が先に出る場合（Bluetooth 遅延など） |
| **遅延をリセット** | <kbd>Ctrl</kbd> + <kbd>\</kbd> | 音声遅延を 0ms にリセット |
