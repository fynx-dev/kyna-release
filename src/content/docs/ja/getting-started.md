# クイックスタート

**Kyna Player** は、Windows 10 / 11 向けに極限まで最適化された、超軽量・高性能な次世代メディアプレイヤーです。Direct3D 11 ハードウェアアクセラレーションレンダリング、完全オフライン対応の Whisper AI 音声文字起こし、アニメ専用 Anime4K 超解像、DLSS 5 拡張を搭載し、最高のオーディオ・ビジュアル体験をお届けします。

---

## ✨ 主な特徴とハイライト

### 🎬 次世代 Direct3D 11 GPU レンダリング
- **ハードウェアアクセラレーション (D3D11VA)**
  デコード処理を GPU に完全オフロード。4K / 8K の超高精細 HEVC / AV1 / VP9 映像を CPU 負荷ほぼゼロで極めてスムーズに再生。
- **HDR トーンマッピング**
  高度な Reinhard / Mobius トーンマッピングにより、SDR ディスプレイでも Dolby Vision や HDR10 の広色域・明暗ディテールを白飛びなく鮮やかに再現。
- **リアルタイム診断 OSD (F12)**
  フレーム生成時間（ms）、ドロップフレーム数、VRAM 使用量を瞬時にオーバーレイ表示。

### 🤖 ローカル Whisper AI 字幕ラボ
- **100% オフライン音声文字起こし**
  ローカル Whisper モデル（`tiny`, `base`, `small`, `medium`, `large-v3`）を搭載。外部サーバーに音声を送信することなく、高精度なタイムスタンプ付き字幕を完全プライベートに生成。
- **LLM コンテキスト翻訳**
  DeepSeek、OpenAI GPT-4o、Claude、ローカル Ollama と連携し、自然で高品質なバイリンガル（2言語併記）字幕を作成。
- **Silero VAD 無音検知**
  BGM や効果音を自動でフィルタリングし、無音区間での AI の幻覚（ハルシネーション）を防止。

### 🎨 Anime4K & ニューラル超解像 (DLSS 5)
- **リアルタイムアニメ超解像**
  アニメ特有のシャープな輪郭線と豊かな色面をリアルタイムに美しく再構築。
- **Compute Shader フォールバック**
  NVIDIA RTX、AMD Radeon、Intel Arc など幅広い GPU アーキテクチャに対応。
- **自動負荷軽減システム**
  GPU 負荷が高まった場合でも 60 FPS の滑らかさを維持するよう自動で処理を最適化。

### 🎛️ ボーダーレスな洗練された UI と豊富なショートカット
- **フレームレス没入型デザイン**
  自動で隠れるコントロールバー、タイムラインサムネイルプレビュー、右側の多機能ドロワー。
- **デュアル字幕表示**
  メイン字幕とサブ字幕を同時に異なるスタイル・フォントで画面に美しく配置。
- **DLNA / UPnP キャスト**
  ローカル映像をスマートテレビ、プロジェクター、Apple TV へワイヤレスで簡単ストリーミング。
