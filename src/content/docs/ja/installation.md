# 📦 インストールとシステム要件

## 💻 動作環境

| 項目 | 最低環境 | 推奨環境 |
| :--- | :--- | :--- |
| **OS** | Windows 10 (64-bit) 1909+ | Windows 11 (22H2+) |
| **CPU** | Intel Core i3 / AMD Ryzen 3 | Intel Core i5 / AMD Ryzen 5 以上 |
| **GPU** | Direct3D 11 ハードウェアデコード対応 | DX12 / HEVC / AV1 / VP9 加速対応 |
| **メモリ (RAM)** | 4 GB | 8 GB 以上 |

---

## 🚀 インストールとアップデート

1. **インストーラーのダウンロード**
   [GitHub Releases](https://github.com/fynx-dev/kyna-release/releases/latest) から `Kyna-Player-vX.Y.Z-windows-x64.exe` をダウンロード。
2. **セットアップウィザード**
   インストーラーを起動し、画面の指示に従って完了させます。
3. **アップデート**
   プレーヤーを終了し、最新のインストーラーを実行して上書きインストールします。設定やダウンロード済みの AI モデルはそのまま保持されます。

---

## 🗄️ アプリデータとログ

インストール版のデータは `%LOCALAPPDATA%\Kyna\` に保存されます。実行ファイルの隣に `data` フォルダがあるポータブル版では、そのフォルダを使用します。ログは `logs\` に保存され、クラッシュダンプは保存を選択した場合にのみ `dumps\` に作成されます。

---

## 🛠️ 起動時にクラッシュした場合

1. **エラーを記録する。** 発生時刻と表示されたエラーコードを控えてください。必須コンポーネントの不足が示された場合は、[公式インストーラー](https://github.com/fynx-dev/kyna-release/releases/latest)で再インストールしてください。必要な MSVC ランタイムは同梱されています。第三者サイトから個別の DLL をダウンロードしないでください。
2. **ログを確認する。** エクスプローラーで `%LOCALAPPDATA%\Kyna\logs` を開き、`kyna-launcher.log` とクラッシュ時刻付近の最新の `kyna-player-*.log` を確認してください。ポータブル版では実行ファイルの隣の `data\logs` も確認してください。
3. **必要な場合だけダンプを保存する。** クラッシュ画面で保存を選ぶと、ローカルに保存されたファイルがエクスプローラーで表示されます。ダンプには個人情報を含むメモリデータが入る可能性があり、自動送信されません。起動前のエラーなどでは作成できない場合があります。公開 Issue に添付しないでください。
4. **Windows のイベントを確認する。** **Win+R** で `eventvwr.msc` を起動し、**Windows ログ → アプリケーション**で該当時刻のエラーを探します。「**障害が発生しているモジュール名**」と「**例外コード**」を控えてください。

[不具合を報告する](https://github.com/fynx-dev/kyna-release/issues/new?template=bug.yml)際は、プレーヤーと Windows のバージョン、再現手順、発生時刻、エラーコード、関連ログを添えてください。一般ログには匿名化処理後も個人情報を含むパスや URL が残る可能性があるため、共有前に確認してください。ダンプは内容とプライバシーへの影響を確認し、非公開の方法でのみ共有してください。
