# 性能調整とトラブル

再生時のカクつきや画面の不具合が発生した場合の対処手順です：

---

## 🛠️ よくある不具合と解決策

### 1. 📺 4K/8K 再生でフレーム落ちやカクつきが発生する
- **GPU 割り当て（デュアル GPU ノート PC）**
  Windows の「設定 → ディスプレイ → グラフィック」で Kyna Player に **「高パフォーマンス (NVIDIA / AMD 独立 GPU)」** を割り当ててください。
- **ハードウェアアクセラレーション**
  映像設定で **「Direct3D 11 (D3D11VA)」** が有効になっているか確認してください。
- **シェーダー負荷**
  Anime4K などの高解像度化フィルターを一時的にオフにするか *Mode Fast* に変更してください。

### 2. 🟢 画面が真っ暗または緑色になり、音声のみ流れる
- **対処法**
  画面を右クリック → **映像** → **「ソフトウェアデコード (CPU)」** に切り替え、GPU ドライバを最新版に更新してください。

### 3. 🌈 SDR 画面で HDR 映像が白っぽく薄い色になる
- **対処法**
  映像設定で **「SDR トーンマッピング」** を有効にし、アルゴリズムを `Reinhard` または `Mobius` に設定してください。
