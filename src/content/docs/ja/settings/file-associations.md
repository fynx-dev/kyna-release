# ファイル関連付け

動画や音声ファイルをダブルクリックした際に Kyna Player で開くよう設定します。

---

## ⚡ ワンクリック関連付け

**設定 → ファイルの関連付け**:
- **「すべての動画形式を関連付ける」** をクリックして MP4, MKV, AVI, MOV, TS, WEBM などを一括登録。
- Windows の「プログラムから開く」メニューに **「Kyna Player」** としてわかりやすく表示されます。
