# フィードバックと診断

不具合を発見した場合や新機能のご提案がある場合は、お気軽にお知らせください。

---

## 📮 公式サポート窓口

- **GitHub Issues**
  [GitHub リポジトリ](https://github.com/fynx-dev/kyna-release/issues) *(バグ報告・機能提案)*
- **コミュニティフォーラム**
  設定の共有や画質調整のディスカッション。

---

## 📋 不具合報告時の推奨記載項目

1. **ソフトバージョン**: 例：`Kyna Player v0.1.0 (x64)`
2. **環境**: Windows 11 23H2 / RTX 4070 (ドライバ: 560.xx)
3. **現象と再現手順**: どのような操作を行った際に問題が発生したか。
4. **添付ファイル**: メディア情報テキスト (<kbd>Ctrl</kbd> + <kbd>I</kbd>)、`kyna_player.log` ログファイル。

> [!NOTE]
> **🔒 プライバシー保証**: ログファイルにはコーデックの動作記録とエラーログのみが含まれます。**個人のプライバシーや再生中の映像キャプチャが収集・送信されることは一切ありません。**
