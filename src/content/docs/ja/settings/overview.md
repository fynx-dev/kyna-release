# 設定センター

お使いのハードウェア環境や好みに合わせて、Kyna Player のあらゆる動作をカスタマイズできます。

---

## 🚪 設定画面の開き方

- **ショートカット**
  <kbd>F2</kbd> または <kbd>Ctrl</kbd> + <kbd>,</kbd>
- **画面ボタン**
  コントロールバー右下の `⚙️ 設定` アイコンをクリック。

---

## 📑 設定カテゴリ

- 🏠 **一般 (General)**
  表示言語、多重起動防止、AppData フォルダへのアクセス。
- ⏯️ **再生 (Playback)**
  デフォルトの再生速度、自動連続再生、シーク移動量。
- 📺 **映像 (Video)**
  Direct3D 11/12 GPU アクセラレーション、HDR トーンマッピング、Anime4K プリセット。
- 🔊 **音声 (Audio)**
  出力デバイス、サラウンドダウンミックス、ナイトモード（DRC）。
- 💬 **字幕 (Subtitles)**
  優先言語、フォント、輪郭線、オンライン字幕プロバイダー。
- 🤖 **AI ラボ (AI Lab)**
  Whisper モデル、LLM API キー、VRAM 自動解放ルール。
- ⌨️ **ショートカット (Hotkeys)**
  キーボードおよびマウス操作の割り当て。
- 🔗 **ファイル関連付け (Files)**
  動画ファイルの規定アプリ登録と右クリックメニュー統合。
