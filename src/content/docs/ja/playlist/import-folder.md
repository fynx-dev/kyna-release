# フォルダ一括追加

アニメの全話フォルダやアルバム全体をワンアクションで取り込めます。

---

## 🚀 取り込み方法

1. **ドラッグ＆ドロップ**: 1つまたは複数のフォルダをプレイヤーウィンドウへ直接ドラッグ。
2. **メニューから開く**: **ファイル → フォルダを開く...**（<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd>）を選択。

---

## 🔍 再帰的スキャンとフィルタリング

- **不要ファイルの除外**
  対応する動画・音声ファイルのみを取り込み、画像や `.nfo`, `.torrent`, ログファイルなどは自動で除外されます。
- **サブフォルダスキャン**
  `Season 1/`, `Season 2/` などの階層構造も自動で探索してまとめます。
- **外部字幕の自動検出**
  同名の `.srt` / `.ass` 字幕が存在する場合、自動的にペアリングされます。
