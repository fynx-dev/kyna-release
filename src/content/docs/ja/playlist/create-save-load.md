# プレイリスト管理

お気に入りの動画や音楽キューを汎用プレイリストとして保存・管理できます。

---

## ➕ プレイリストの作成と管理

1. **新規リスト**: プレイリスト上部の `➕ 新規` をクリックして空のリストを作成。
2. **ファイルの追加**: 「ファイルを追加」またはエクスプローラーからドラッグ＆ドロップ。
3. **順序調整**: アイテムをドラッグして再生順を変更。

---

## 💾 保存とエクスポート (M3U8)

- **プレイリストを保存**
  **「💾 保存 / 名前を付けて保存」** をクリック。
- **M3U8 (UTF-8)** *(推奨)*: 日本語や特殊記号を含むファイル名でも文字化けせずに保存。
- **相対パス対応**
  相対パスで保存されるため、外付け HDD に移動してもそのまま再生可能です。
