# 再生履歴とファイル

過去に再生したメディアの履歴確認や、ローカルファイルの整理をプレイヤー上から行えます。

---

## 📜 最近の再生履歴

- **レジュームマーク**
  前回の停止位置を表示（例：`45:12 まで再生 (68%)`）。
- **ワンクリック再開**
  ダブルクリックで中断した場所から即座に再生再開。
- **プライバシー保護**
  「履歴を消去」をクリックするとすべての履歴がクリアされます。

---

## 🗂️ コンテキストメニューのファイル操作

リスト内のアイテムを右クリック：
- **ファイルの場所を開く**
  <kbd>Ctrl</kbd> + <kbd>E</kbd> でエクスプローラーを表示。
- **リストから削除**
  <kbd>Delete</kbd>（ディスク上の実ファイルは削除されません）。
- **ごみ箱へ移動**
  <kbd>Shift</kbd> + <kbd>Delete</kbd>（見終わったファイルを Windows のごみ箱へ直接移動）。
- **ファイルパスをコピー**
  <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd>
