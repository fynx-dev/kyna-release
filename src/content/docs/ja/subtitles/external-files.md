# 外部字幕の読み込み

ダウンロードした外部字幕ファイルの追加や、動画ファイルとの自動ペアリングに対応しています。

---

## 📥 外部字幕の読み込み方法

1. **ドラッグ＆ドロップ**: `.srt`, `.ass`, `.vtt`, `.sub` ファイルを再生中の画面に直接ドラッグします。
2. **ファイルダイアログ**: <kbd>Ctrl</kbd> + <kbd>L</kbd> キーを押して字幕ファイルを選択します。
3. **同名自動読み込み**: 動画と同じフォルダにある `[動画ファイル名].*.srt` 形式の字幕を自動で検出してロードします。
