# 内蔵字幕とデュアル字幕

MKV や MP4 に複数言語の字幕が収録されている場合、Kyna Player の**デュアル字幕システム**を使用することで、外国語学習やバイリンガル視聴が快適に行えます。

---

## 📑 字幕トラックの選択と切り替え

- **字幕ドロワー**
  <kbd>Alt</kbd> + <kbd>S</kbd> で開きます。
- **右クリックメニュー**
  画面を右クリック → **字幕** → **字幕トラック**。
- **巡回ショートカット**
  <kbd>V</kbd> キーを押すごとに利用可能なトラックと「オフ」が切り替わります。

---

## 👥 デュアル字幕システム（2言語同時表示）

メイン字幕とサブ字幕を同時に画面上に表示できます：
- **メイン字幕**
  母語（日本語など、大きめのフォントで表示）。
- **サブ字幕**
  原語（英語や韓国語など、メイン字幕の上下に小さめのフォントで配置）。
- **独立レイアウト**
  メインとサブで個別のフォントサイズ、位置オフセット、色を設定でき、重なりを防ぎます。

---

## 🎯 優先言語の自動設定

**設定 → 字幕設定** であらかじめ設定：
- **第1優先言語コード**
  例：`ja, jpn, 日本語`
- **第2優先言語コード**
  例：`en, eng, 英語`
- 新しい動画を開いた際、一致する字幕トラックが自動的に選択されます。

---

## 📦 対応字幕フォーマット

| 形式 | 特徴 | Kyna Player の対応状況 |
| :--- | :--- | :--- |
| **ASS / SSA** | 複雑なアニメーション、スタイル、位置指定に対応 | libass による完全なハードウェア描画 |
| **SRT** | プレーンテキスト標準 | フォント・スタイルの自由なカスタマイズに対応 |
| **VTT** | Web ストリーミング標準 | 完全対応 |
| **PGS / SUP** | ブルーレイビットマップ画像字幕 | 高品位ビットマップ描画に対応 |
