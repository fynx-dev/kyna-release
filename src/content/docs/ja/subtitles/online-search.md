# オンライン字幕検索

ブラウザを開いて字幕を探すことなく、Kyna Player 内でワンクリックで最適な字幕を検索・ダウンロードできます。

---

## 🔍 検索と読み込みの流れ

1. **検索の開始**: <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> を押すか、字幕ドロワーの **「🌐 オンライン字幕を検索」** をクリック。
2. **デュアル照合**:
   - **ハッシュ照合**
  動画ファイルの固有チェックサムを用いて、タイミングが100%一致する字幕をピンポイント特定。
   - **タイトル検索**
  ハッシュが見つからない場合、タイトルや話数（`S01E05` など）から自動検索。
3. **ワンクリック適用**: 検索結果から目的の字幕をクリックすると、即座にダウンロードされて動画に反映されます。
