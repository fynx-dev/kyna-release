# 增强对比与性能

在使用 **Anime4K**、**DLSS 5** 或高级着色器滤镜时，为了让用户直观检验画质提升幅度并确保播放过程绝不卡顿，Kyna Player 内置了专业的**画质对比分屏工具**与**实时性能监控与回退引擎**。

---

## 🔀 实时画质对比视图 (Comparison Views)

在开启视频增强滤镜后，你可以通过画质控制面板或快捷键唤出对比模式：

| 对比模式 | 展现形式与特点 | 适用排查 |
| :--- | :--- | :--- |
| **左右分屏 (Side-by-Side)** | 画面左侧呈现原始画面，右侧呈现 AI/滤镜增强后的画面，支持拖动中间分界线。 | 直观对比动漫线条锐化程度与噪点消除效果 |
| **上下分屏 (Top-Bottom)** | 上半部分为原画，下半部分为增强画质。 | 适合宽屏横幅景观画面对比 |
| **差异热力视图 (Difference / Heatmap)** | 纯黑背景上高亮显示增强算法所修改/补全的像素高频细节。 | 专业评估算法是否产生了伪影或过度锐化 |


## ⏱️ GPU 性能预算与帧时间监控 (Frame Time Budget)

实时视频增强是一项计算密集型任务。以 60 FPS 视频为例，每一帧的解码、滤镜着色与合成必须在 **16.6 毫秒 (ms)** 内全部完成：

```
[ 视频帧解码 (3ms) ] + [ GPU 增强计算 (8ms) ] + [ 画面送显 (2ms) ] = 13ms  ✅ 预算内 (流畅)
[ 视频帧解码 (5ms) ] + [ GPU 增强计算 (14ms) ] + [ 画面送显 (2ms) ] = 21ms ❌ 超出预算 (掉帧)
```

- **微型性能统计 OSD**
  按快捷键 <kbd>F12</kbd> 可实时查看每帧消耗的精确毫秒数、GPU 显存占用与瞬时丢帧统计。

## 🛡️ 智能自动回退机制 (Dynamic Fallback)

为了防止因 GPU 负载突发过高导致播放画面严重卡顿或音画不同步，Kyna Player 设计了双重回退策略：

### 1. 流畅优先（默认策略）
- 当检测到连续 3 帧增强计算超出渲染时间预算时，播放器会**无缝回退至轻量级算法或原始画面**，优先保障 60 FPS 画面绝对流畅与声音连续。
- 当 GPU 负载降低、算力富余时，自动恢复高精度增强算法。

### 2. 画质优先（Quality Locked）
- 在设置中开启“画质优先”后，播放器将强制 GPU 执行完整的超分辨率/滤镜运算，绝不跳过计算。
- *注意*：若显卡性能不足，可能会导致偶发掉帧，建议仅在独立高性能显卡上开启。

## 💡 最佳调优建议

> [!TIP]
> - **笔记本移动显卡**：在未插电源适配器（电池供电）时，建议使用轻量预设（如 Anime4K Mode A - Fast），避免触发降频回退。
> - **4K 视频无需过度超分**：若片源本身已经是 4K 高码率原盘，无需开启 2x 超分辨率，开启轻微边缘抗锯齿滤镜即可获得最佳观感。
