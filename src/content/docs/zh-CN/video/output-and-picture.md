# 视频输出与画质

Kyna Player 采用先进的 Direct3D 硬件渲染管线，不仅能够发挥 GPU 的极致解码渲染性能，还提供了灵活的画面比例调整、色彩校准以及 HDR 高动态范围支持。

---

## 🚀 视频输出与硬件解码 (Hardware Acceleration)

在 **设置 → 视频与渲染** 中，你可以选择适合当前硬件架构的渲染后端：

| 渲染输出模式 | 特点与优势 | 适用场景 |
| :--- | :--- | :--- |
| **Direct3D 11 (D3D11)** *(推荐)* | 极高的兼容性与极低的延迟，支持零拷贝 GPU 解码直接送显 | Windows 10/11 绝大多数独立显卡与核显 |
| **Direct3D 12 (D3D12)** | 面向现代 GPU 优化的底层渲染，支持更复杂的着色器计算 | 现代独立显卡 (RTX / RX 系列) |
| **CPU 软件解码 (Software)** | 完全使用 CPU 进行像素解码与处理，兼容性最高 | 遇到老旧或特殊非标编码格式时的保底手段 |

> [!TIP]
> 开启 **D3D11 硬件加速** 后，播放 4K 120fps 或 8K 超高清 HEVC/AV1 视频时，CPU 占用率通常能保持在 5% 以下。

## 📐 画面比例与缩放模式 (Aspect Ratio)

按快捷键 <kbd>A</kbd> 或在右键菜单的 **画面比例** 中快速切换：

- **保持原片比例 (Fit / Keep Aspect Ratio)** *(默认)*：保持视频原始物理宽高比，在视口边缘保留黑色遮幅，杜绝画面拉伸变形。
- **拉伸铺满窗口 (Stretch)**
  强制将画面拉伸填满整个播放器窗口（适合特定 4:3 老电影强制 16:9 铺满）。
- **裁剪填充 (Crop to Fill)**
  等比例放大画面直至完全填满窗口，裁剪多余上下或左右边缘，消除黑边。
- **自定义比例强制转换**
  手动锁定为 `16:9`、`4:3`、`21:9`（带鱼屏超宽屏电影）或 `1:1`。

## 🎚️ 色彩与画质微调 (Color Calibration)

在侧边栏的 **画质面板** 或 **设置 → 画面调节** 中，可以对画面各项色彩指标进行实时非破坏性调节：

```
[亮度 Brightness]   -50 ───────●─────── +50   (默认 0)
[对比度 Contrast]   -50 ───────●─────── +50   (默认 0)
[饱和度 Saturation] -50 ───────●─────── +50   (默认 0)
[色相 Hue]          -180 ──────●────── +180  (默认 0)
[伽马 Gamma]        0.5 ───────●─────── 2.0   (默认 1.0)
```

- **亮度 / 对比度**
  快速提亮暗部细节或提升电影画面的层次感。
- **饱和度**
  增强动漫与自然风景的色彩鲜艳度，或拉至最低转化为黑白电影胶片风格。
- **一键重置**
  点击“重置默认值”一键恢复原片色彩。

## 🔄 画面旋转与镜像翻转 (Rotate & Flip)

对于手机竖屏录制方向错误，或舞蹈练习镜面翻转需求：
- **顺时针旋转 90°**
  快捷键 <kbd>Alt</kbd> + <kbd>R</kbd>（循环 90° -> 180° -> 270° -> 0°）。
- **水平镜像翻转 (Mirror Flip)**
  快捷键 <kbd>Alt</kbd> + <kbd>H</kbd>（舞蹈翻跳与肢体动作学习神器）。
- **垂直翻转**
  快捷键 <kbd>Alt</kbd> + <kbd>V</kbd>。

## 🌈 HDR 高动态范围与色调映射 (HDR & Tonemapping)

当播放 4K HDR10 / HLG / 杜比视界 (Dolby Vision) 媒体时：
1. **HDR 显示器直出 (Passthrough)**：若系统已开启 Windows HDR，播放器直接向显示器输出 10-bit BT.2020 广色域与高动态亮度信号，还原极亮与纯黑细节。
2. **SDR 智能色调映射 (Tonemapping)**：若在标准 SDR 显示器上播放 HDR 视频，播放器将采用高质量 Reinhard / Mobius 算法自动进行色域压缩，避免画面发灰、过曝或失真。
