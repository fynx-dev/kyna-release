# 高级滤镜与增强

除了广受欢迎的 Anime4K 二次元画质增强外，Kyna Player 还搭载了面向电影实拍片源、老旧胶片修复以及现代 GPU 算力优化的多项**实验性着色器滤镜**与 **AI 神经超分管线**。

---

## ⚡ DLSS 5 神经超分辨率增强

针对拥有现代独立显卡的用户，Kyna Player 提供了前沿的神经超分辨率管线：

- **硬件自动侦测与智能路由**
  自动检测系统中的高性能独立显卡，无感完成计算上下文初始化。
- **Compute Shader 通用兼容**
  不仅支持专用加速核心，还内置基于通用 Direct3D Compute Shader 的无损回退实现，确保在各类 GPU 架构上稳定运行。
- **自适应时间序列抗锯齿**
  有效抑制电影高频边缘的闪烁与摩尔纹，呈现丝滑自然的物理超清画面。

## 🔬 常用画质修复滤镜库

在侧边栏的 **画质面板 → 高级着色器** 中，可随时组合叠加以下滤镜：

| 滤镜名称 | 核心算法原理 | 解决的画质痛点 |
| :--- | :--- | :--- |
| **CAS (自适应锐化)** | Contrast Adaptive Sharpening | 提升模糊画面边缘清晰度，智能抑制过度锐化产生的白边光晕。 |
| **Deband (去色带)** | 梯度散色与抖动随机化 (Dithering) | 消除天空、渐变背景、夜景暗部中难看的阶梯状色彩断层与色带。 |
| **Bilateral (双边保边降噪)** | 结合空间距离与像素相似度的双边滤波 | 消除高 ISO 噪点或压缩颗粒，同时完整保留人物发丝与建筑轮廓。 |
| **Film Grain (胶片颗粒模拟)** | 高品质高斯噪声生成器 | 为过于干净的数字视频添加复古胶片质感，掩盖轻微压缩失真。 |

## 🎛️ 滤镜启用、叠加与管理

```
[ 原始解码帧 ] ──> [ Deband 去色带 ] ──> [ CAS 锐化 ] ──> [ 屏幕渲染呈现 ]
```

1. **链式叠加**：支持按需串联多个着色器滤镜，例如先进行 *Deband 去色带* 再进行 *CAS 锐化*。
2. **强度滑块微调**：每个滤镜均提供从 `0.0` 到 `1.0` 的强度滑动条，方便按个人偏好微调。
3. **一键旁路对比 (Bypass)**：按住快捷键可临时关闭所有滤镜查看原始画面，松开立即重新开启。
4. **一键重置清空**：点击面板顶部的“重置滤镜”，瞬间释放 GPU 着色器资源并恢复原始纯净输出。

## ⚠️ 兼容性与使用注意事项

> [!IMPORTANT]
> - **驱动与显卡要求**：高级着色器滤镜和 DLSS 5 增强需依赖 GPU Direct3D 11/12 支持。建议将显卡驱动升级至最新版本。
> - **超高分辨率片源建议**：对于已经达到 4K (3840x2160) 的高质量高码率原盘片源，建议仅开启轻度 CAS 锐化或 Deband，无需开启高倍超分计算。
