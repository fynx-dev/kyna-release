# 媒体属性与诊断

无论是极客玩家想要探究 4K 压制参数，还是排查特殊视频文件播放异常，Kyna Player 提供了极为详尽的**媒体元数据面板**与**实时播放诊断引擎**。

---

## 🔍 打开媒体属性面板

- **快捷键**
  按下 <kbd>Ctrl</kbd> + <kbd>I</kbd> 或 <kbd>Shift</kbd> + <kbd>I</kbd>。
- **菜单入口**
  在画面上右键单击 → **工具 (Tools)** → **媒体信息 (Media Info)**。

---

## 📊 媒体参数全景解析

属性面板将媒体信息清晰划分为以下模块：

```
+-------------------------------------------------------------+
| 📁 容器信息: Matroska (.mkv) | 大小: 14.2 GB | 总码率: 18.5 Mbps |
+-------------------------------------------------------------+
| 📺 视频流 #0:                                                |
|   • 编码格式: HEVC (H.265) Main 10 @ L5.1 @ High             |
|   • 画面尺寸: 3840 × 2160 (4K UHD, 16:9)                    |
|   • 帧率模式: 23.976 FPS (恒定帧率 CFR)                     |
|   • 色彩空间: BT.2020 广色域 / 10-bit 色深 / YUV 4:2:0       |
|   • HDR 标准: HDR10 (Mastering Display: 1000 nits)          |
+-------------------------------------------------------------+
| 🔊 音频流 #1:                                                |
|   • 编码格式: DTS-HD MA (7.1 声道 / 48 kHz / 24-bit)        |
+-------------------------------------------------------------+
| 💬 字幕流 (共 3 轨):                                         |
|   • #2 简体中文 (ASS 特效) | #3 繁體中文 | #4 English (SRT)   |
+-------------------------------------------------------------+
```

## ⚡ 实时播放管线诊断 (Live Diagnostics)

在面板的 **“运行状态”** 标签页中，可以实时监测底层的解码与渲染表现：

- **硬件解码器状态**
  显示当前正在运作的硬件加速驱动（如 `D3D11VA - NVIDIA NVDEC (HEVC)` 或 `CPU FFmpeg Native`）。
- **实时瞬时码率 (Bitrate Graph)**
  动态曲线展示视频峰值码率。
- **渲染帧率与丢帧统计**
  精准显示送显帧率 (FPS) 及累计丢帧数 (Dropped Frames: 0)，瞬间确认系统是否流畅。

## 📋 一键复制与技术支持分享

- 点击面板底部的 **“复制全部信息”** 按钮，系统会将规范格式的媒体诊断文本复制到剪贴板。在向社区求助或提交 Bug 反馈时，可直接粘贴提供给开发团队。
