# 截图与保存管理

在观看高清电影或精美动漫时，遇到惊艳画面想要作为桌面壁纸或分享给朋友？Kyna Player 提供了极速的原生尺寸**无损截图引擎**。

---

## ⚡ 截图快捷操作与模式

| 操作目标 | 快捷键 | 截取特性与说明 |
| :--- | :--- | :--- |
| **标准原画截图** *(推荐)* | <kbd>Ctrl</kbd> + <kbd>S</kbd> / <kbd>F5</kbd> | 直接抓取视频原生分辨率的像素，**不带字幕**，画面纯净。 |
| **带字幕画面截图** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 将当前视频画面连同当前渲染的**外挂/内嵌字幕**一并截取。 |
| **快速复制到剪贴板** | <kbd>Ctrl</kbd> + <kbd>C</kbd> | 不生成本地文件，直接将截图像素复制到剪贴板，方便在聊天软件（微信/QQ/Discord）中 <kbd>Ctrl</kbd>+<kbd>V</kbd> 直接发送。 |

---

## 📂 截图文件命名模板与格式

在 **设置 → 截图设置** 中，可自由配置截图的输出细节：

### 1. 图像输出格式
- **PNG (无损)** *(默认)*：色彩无损、无压缩伪影，适合制作壁纸与高质量画集。
- **JPEG (高品质)**
  文件体积小（质量可设为 95%），适合快速分享。
- **WebP**
  兼顾超高压缩比与清晰画质。

### 2. 自定义命名模板
支持使用动态变量构建规范的文件名：
- 默认模板：`{title}_{time}_{index}.png`
- 实际输出示例：`Inception.2010_01-24-36_001.png`
- 可用变量：`{title}` (视频名)、`{time}` (当前时间戳)、`{date}` (当前日期)、`{index}` (自增编号)。

### 3. 存储路径与快速访问
- 默认保存于 Windows 系统 `Pictures/KynaPlayer/` 目录。
- 截图完成后，屏幕顶部会弹出 Toast 提示，点击 Toast 中的 **“打开文件夹”** 按钮即可直达截图所在路径。
