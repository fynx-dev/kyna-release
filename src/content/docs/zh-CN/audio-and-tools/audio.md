# 音轨与音画同步

Kyna Player 搭载了高保真音频渲染管线，支持多声道环绕声直通（Bitstream Passthrough）、多音轨随心切换以及精准的音画同步校准。

---

## 🎧 多音轨识别与切换 (Audio Tracks)

对于包含国语/粤语/英语多语种配音或导演评论音轨的视频：

- **快捷键切换**
  按下快捷键 <kbd>A</kbd> 或 <kbd>Ctrl</kbd> + <kbd>A</kbd> 快速轮换可用音轨。
- **右键菜单选择**
  在画面上右键单击 → **音频 (Audio)** → **音轨选择**。
- **音轨信息清晰展现**
  列表中会完整标明音轨语言、编码格式（如 `DTS-HD MA 7.1`、`Dolby TrueHD Atmos`、`AAC 2.0`、`FLAC`）以及采样率与声道数。

---

## 🎛️ 音频输出设备与声道配置 (Audio Device)

在 **设置 → 音频偏好** 中，你可以定制音频输出链路：

### 1. 独立输出设备选择
- 支持将播放器声音独立输出至指定的耳机、蓝牙音箱、USB 外置 DAC 解码器或电视 HDMI 接口，不干扰系统其他软件的声音播放。

### 2. 多声道智能下混 (Downmix)
- 当在普通双声道立体声耳机/音箱上播放 5.1 / 7.1 环绕声音源时，播放器会自动启用高质量 HRTF 空间混音算法，确保中置人声对白清晰，杜绝爆音与人声发闷。

### 3. 音频直通透传 (S/PDIF / HDMI Passthrough)
- 若连接了支持 Dolby / DTS 硬解码的家庭影院功放，可开启直通透传，将原始比特流直接交由外部独立硬件解码。

---

## ⏱️ 音画同步微调 (Audio Delay Sync)

当使用高延迟蓝牙耳机（如早期蓝牙设备）导致口型与声音不同步时：

| 操作 | 快捷键 | 效果说明 |
| :--- | :--- | :--- |
| **音频延后 100 毫秒** | <kbd>Ctrl</kbd> + <kbd>]</kbd> | 延后声音发出（修正声音抢跑于画面） |
| **音频提前 100 毫秒** | <kbd>Ctrl</kbd> + <kbd>[</kbd> | 提前声音发出（修正画面抢跑于声音） |
| **重置音频同步** | <kbd>Ctrl</kbd> + <kbd>\</kbd> | 清除延迟偏置，恢复 0 毫秒 |

> [!TIP]
> 调整时屏幕上方会弹出 HUD 提示当前的毫秒级音画偏移量（例如 `音频同步: -200 ms`）。
