# DLNA 电视投屏

想把电脑上的 4K 电影或追番剧集无线投放到客厅大屏电视或投影仪上观看？Kyna Player 内置了开箱即用的 **DLNA / UPnP 数字媒体控制器（DMC）**。

---

## 📡 投屏快速使用指南

```
[ 电脑运行 Kyna Player ] ── (局域网 Wi-Fi / 有线网络) ──> [ 客厅智能电视 / 投影仪 ]
           │                                                      ▲
           └────────────── 同步控制播放 / 进度 / 音量 ──────────────┘
```

### 1. 发现可用投屏设备
- 打开侧边栏 **工具面板 → DLNA 投屏**，或点击控制栏的 `📺 投屏` 图标。
- 播放器将自动扫描局域网内的兼容设备（如小米电视、华为智慧屏、索尼电视、LG WebOS、Apple TV 投屏接收端、各类 Android 电视盒子）。

### 2. 开始投放
- 在设备列表中找到目标电视名称（例如 `Living Room TV`），点击 **“连接并投放”**。
- 电视端将自动拉起大屏播放界面，电脑端则转为投屏遥控器控制台。

### 3. 全能多媒体遥控器
- **进度同步**
  在 Kyna Player 上拖动进度条，电视端同步毫秒级跳转。
- **音量调节**
  直接通过电脑调节电视物理音量。
- **播放列表连播**
  当前集在电视上播放完毕后，自动推送下一集至大屏。

---

## 🛠️ 常见投屏排错与注意事项

> [!IMPORTANT]
> - **处于同一局域网**：确保电脑与电视连接在同一个路由器 Wi-Fi（建议 5GHz 频段）或有线局域网下，隔离的“访客 Wi-Fi”无法互相发现。
> - **Windows 防火墙放行**：首次使用时，Windows 系统若弹出防火墙安全警报，请务必勾选 **“专用网络”** 并点击“允许访问”。
> - **大屏解码兼容性**：投屏传输的是媒体原始流，若电视端芯片不支持特定新格式（如 10-bit AV1），可在投屏设置中开启 *“实时转码推流兼容模式”*。
