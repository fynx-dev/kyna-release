# ⏯️ 播控与快捷导航

Kyna Player 提供极速响应的播控引擎，支持毫秒级精准 Seek 与全键盘操作。

---

## 🎮 常用快捷键速查

| 操作 | 默认快捷键 | 鼠标操作 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **播放 / 暂停** | <kbd>Space</kbd> | 单击画面中央 | 切换播放与暂停状态 |
| **停止播放** | <kbd>S</kbd> | 控制栏停止按钮 | 停止解码并重置进度至起点 |
| **全屏切换** | <kbd>F</kbd> | 双击画面 | 进入 / 退出全屏模式 |
| **退出全屏 / 浮层** | <kbd>Escape</kbd> | - | 退出全屏或关闭当前打开的浮窗面板 |
| **单帧前进** | <kbd>.</kbd> | - | 暂停时向前移动精确的一帧 |
| **音量调节** | <kbd>↑</kbd> / <kbd>↓</kbd> | 滚轮上下滚动 | 调节播放音量 |
| **静音切换** | <kbd>M</kbd> | 点击音量图标 | 快速静音 / 恢复音量 |
| **打开文件** | <kbd>O</kbd> | 点击打开按钮 | 呼出系统文件选择对话框 |
| **性能统计 OSD** | <kbd>Tab</kbd> | - | 实时显示帧率 (FPS)、丢帧数、码率与渲染耗时 |

## ⏳ 进度条与悬停缩略图

![时间轴缩略图预览](/assets/images/features/thumbnails.webp)

- **悬停缩略图**
  鼠标悬停于进度条上方任意位置，实时预览对应关键帧画面与时间戳。
- **步进快进/快退**
  按方向键 <kbd>→</kbd> / <kbd>←</kbd>，毫秒级快速跳转前后进度。

---

## 🔁 循环与播放策略

点击控制栏右下角的循环图标切换播放模式：
- 🔁 **列表循环**：全部播放完后从头循环，适合连续追剧。
- 🔂 **单曲循环**：当前视频无限循环，适合舞蹈与技能学习。
- 🔀 **随机播放**：列表随机乱序播放，适合音乐库。
- ➡️ **顺序播放**：播至列表末尾后自动停止。
