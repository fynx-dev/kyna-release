## 常用播放控制快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| `Space` / `K` | 播放 / 暂停 |
| `Left` / `Right` | 后退 / 前进 5 秒 |
| `Shift` + `Left` / `Right` | 后退 / 前进 15 秒 |
| `Up` / `Down` | 调高 / 调低音量 (5%) |
| `M` | 静音 / 取消静音 |
| `F` / `Enter` | 进入 / 退出全屏模式 |
| `Esc` | 退出全屏 / 退出小窗 |
