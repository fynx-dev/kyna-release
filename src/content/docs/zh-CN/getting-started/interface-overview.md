# 界面导览

Kyna Player 采用了极简现代的**无边框沉浸式设计**，在保证视听画面不受干扰的同时，提供了极其直观高效的控制面板与侧边栏抽屉。

---

## 📐 界面区域总览

![界面布局概览](/assets/images/docs/getting-started/openfile-playlist-settings.png)

Kyna Player 的主界面主要由以下 4 大核心区域组成：

```
+-------------------------------------------------------------+
| 🏷️ 标题栏 (窗口控制 / 置顶 / 媒体标题)                         |
+-------------------------------------------------------------+
|                                                             |
|                                            +--------------+ |
|                                            |              | |
|                    📺 视频渲染主视口         |  📑 侧边栏   | |
|                 (手势交互 / 画面缩放)       |  (抽屉面板)  | |
|                                            |              | |
|                                            +--------------+ |
+-------------------------------------------------------------+
| 🎛️ 底部悬浮控制栏 (进度条 / 播放控制 / 音量 / 工具入口)       |
+-------------------------------------------------------------+
```

---

## 1. 🏷️ 顶部标题栏 (Title Bar)

当鼠标移动至窗口顶部时，标题栏会自动显现（全屏模式下自动隐藏）：
- **📌 窗口置顶按钮**
  一键将播放器固定在所有窗口最前端，边看视频边工作/聊天。
- **🎬 当前媒体标题**
  显示正在播放的视频或音频文件名。
- **⚙️ 窗口状态控制**
  最小化、最大化 / 还原、关闭窗口。

---

## 2. 📺 视频渲染主视口 (Video Viewport)

核心视频画面展示区域，基于 GPU 硬件加速渲染，支持丰富的直觉交互：

| 动作 | 对应操作与响应 |
| :--- | :--- |
| **单击画面** | 播放 / 暂停切换（可选配置） |
| **双击画面** | 快速进入 / 退出全屏模式 |
| **滚轮滚动** | 快速调节音量大小（步进 ±5%） |
| **鼠标拖拽进度** | 画面正中央显示大幅时间与跳转预览 |
| **拖入文件** | 直接拖放视频、音频或字幕文件加载 |
| **右键菜单** | 唤出完整的全局右键功能菜单（打开、轨道选择、滤镜、设置等） |

---

## 3. 🎛️ 底部悬浮控制栏 (Control Bar)

控制栏常驻或随鼠标悬浮弹出，集成所有常用播控功能：

### ⏳ 交互式时间轴与进度条
- **悬停缩略图**
  鼠标划过时间轴时，实时显示关键帧缩略图预览与时间戳点。
- **精确定位**
  点击时间轴任意位置即刻快速 Seek，支持平滑拖拽。
- **时间标签**
  左侧显示当前播放时间，右侧显示视频总时长 / 剩余时间。

### ⏯️ 核心播控按键组
- **上一曲 / 下一曲**
  快速切换播放列表中的上下文件（快捷键：`PageUp` / `PageDown`）。
- **播放 / 暂停**
  大图标核心控制（快捷键：`Space`）。
- **停止播放**
  停止解码并重置进度。
- **逐帧微调**
  支持单帧前进/后退，方便截取精准画面。

### 🔊 音量与音频快捷调节
- **静音切换**
  点击喇叭图标一键静音/恢复。
- **音量滑条**
  水平滑块平滑调节 0% ~ 200% 音量（支持音量额外增益）。

### ⚡ 功能快捷入口
- **倍速切换**
  快速选择 `0.5x`、`1.0x`、`1.25x`、`1.5x`、`2.0x` 或自定义倍速。
- **播放循环模式**
  单曲循环、列表循环、随机播放、顺序播放一键切换。
- **侧边栏快捷切换**
  播放列表、字幕库、画质滤镜、AI 工具箱一键展开。

---

## 4. 📑 侧边栏抽屉 (Sidebar Drawer)

点击控制栏右侧图标或使用快捷键，即可从右侧划出多功能抽屉面板：

| 面板名称 | 核心功能说明 | 推荐快捷键 |
| :--- | :--- | :--- |
| 📑 **播放列表 (Playlist)** | 查看文件列表、管理播放顺序、搜索媒体、导入文件夹 | `F3` / `Alt+P` |
| 💬 **字幕与音频 (Tracks)** | 内置/外挂字幕切换、双字幕对照、字体样式调节、音轨选择 | `Alt+S` |
| 🤖 **AI 实验室 (AI Lab)** | 本地 Whisper 语音转录、大模型双语字幕翻译、实时字幕生成 | `Alt+A` |
| ✨ **画质与滤镜 (Video)** | Anime4K 超分辨率、DLSS 5 增强、着色器滤镜、色彩调节 | `Alt+V` |
| ⚙️ **偏好设置 (Settings)** | 硬件解码、文件关联、快捷键自定义、UI 语言切换 | `F2` / `Ctrl+,` |

---

## 💡 界面使用小技巧

> [!TIP]
> - **无干扰纯享模式**：播放视频时将鼠标移出窗口，控制栏和标题栏将在 2 秒后自动淡出。
> - **键盘优先**：Kyna Player 几乎所有界面按钮均对应有快捷键，建议查阅 [播放控制与快捷键](/docs/zh-CN/playback/controls/) 获得极速操控体验！
