**Kyna Player** 提供了多种灵活便捷的媒体打开方式。无论是本地单个文件、批量多文件、整个剧集目录、标准 M3U 播放列表，还是网络直播与流媒体链接，都能快速加载并流畅播放。

---

## 📂 1. 打开本地媒体文件

### 快速打开方式
- **快捷键**
  按下快捷键 <kbd>O</kbd> 呼出 Windows 原生文件选择对话框。
- **界面按钮**
  点击标题栏菜单或播放控制栏中的 **打开文件** 按钮。
- **支持格式**
  支持 MP4、MKV、AVI、MOV、WEBM、FLV、WMV、TS、M2TS、M4V、RMVB、3GP、VOB 等几乎所有主流音视频封装格式。

![打开文件菜单](/assets/images/docs/getting-started/openfile-menu.png)

### 打开文件行为（列表策略）
你可以在 **设置 → 播放列表** 中自由选择打开新文件时的默认行为：
- 🔄 **替换并播放**（默认）
  清空当前的临时播放列表，立即开始播放新选中的文件。
- ➕ **追加并播放**
  保留当前列表中的内容，将新选择的文件追加到列表末尾，并立即开始播放新文件。

![播放列表设置](/assets/images/docs/getting-started/openfile-playlist-settings.png)

## 🖱️ 2. 拖放媒体与文件夹智能导入

### 拖放文件
直接将 Windows 资源管理器中的一个或多个视频/音频文件拖入播放器窗口任意位置，即可立即触发播放并根据上述打开行为更新播放列表。

### 拖放文件夹（智能批量扫描）
当你将整个影视剧集或音乐文件夹拖入窗口时，播放器会自动弹出 **文件夹导入** 对话框：
- 🔍 **递归扫描**
  勾选“扫描子文件夹”可递归遍历目录下所有层级的媒体文件。
- 📊 **实时统计**
  实时显示当前正在扫描的路径及已发现的媒体文件数量。
- ⚡ **一键导入**
  扫描完成后自动按文件名自然排序并批量加入播放列表。

![拖放文件与文件夹扫描](/assets/images/docs/getting-started/drag-files-and-folder.png)

## 📜 3. 打开与管理播放列表

- **支持格式**
  支持直接加载 `.m3u` 与 `.m3u8` 格式的播放列表文件。
- **侧边栏列表管理**
  - 点击播放控制栏的 **播放列表** 图标（或使用快捷键）展开侧边栏。
  - 支持 **加载列表**、**保存列表**、**另存为** 与 **清空列表**。
  - 🛡️ **防丢失保护**
  若当前播放列表有未保存的变动，切换或清空前播放器会主动弹出确认提示。

## 🌐 4. 打开网络流媒体 (URL)

在打开菜单中选择 **打开 URL**，即可呼出网络流媒体播放窗口：

### 支持的流媒体协议
- 📡 **HTTP / HTTPS 直链**
  MP4/MKV/WebM 等网络静态视频文件直链。
- 📺 **HLS 流媒体**
  支持 `.m3u8` 在线直播流与分段点播流。
- 📹 **实时流协议**
  支持 RTSP、RTMP 等实时推流与监控流播放。

### 历史记录管理器
- 播放器会自动记录最近播放过的网络 URL（最高保留 30 条）。
- 再次打开时无需重复输入或粘贴，在历史记录列表中单击即可极速重播。
- 支持单个条目删除或一键清空全部历史。

![打开 URL 窗口](/assets/images/docs/getting-started/open-url-dialog.png)

## 🕒 5. 最近播放记录与记忆续播

- **断点记忆续播**
  对于曾经播放过的媒体，Kyna Player 会自动记住上次退出的播放进度、选中的音轨与外挂字幕，再次打开时会自动无缝续播。
- **最近打开菜单**
  在控制栏或主菜单的 **最近文件** 列表中，可以快速回溯并播放最近观看的本地影视。

---

## 🪟 6. 系统级文件关联与右键菜单

在 **设置 → 文件关联** 页面中：
- 📑 **格式关联**
  勾选常见视频格式后点击“应用”，即可将视频文件默认关联至 Kyna Player，双击文件直接启动播放。
- 🖱️ **右键菜单集成**
  勾选“启用右键菜单快捷播放”，可在 Windows 资源管理器右键菜单中添加 **“用 Kyna Player 打开”**（Play with Kyna Player）选项。

## ❓ 常见问题排查

| 现象 | 可能原因与解决方法 |
| :--- | :--- |
| **打开文件提示不存在** | 文件已被移动、重命名或处于未挂载的外置磁盘，请检查文件实际路径。 |
| **网络 URL 无法加载** | 检查网络连接是否通畅、流媒体源是否已失效或过期，以及目标链接是否需要特定 Header/Token 认证。 |
| **双击视频未能用 Kyna 打开** | 请前往 **设置 → 通用** 点击“打开 Windows 设置”，在系统“默认应用”中将 Kyna Player 设为默认视频播放器。 |
