**Kyna Player** 提供了直观流畅的基础播控体验，支持通过鼠标手势、触控操作以及高度契合习惯的键盘快捷键进行操作。

---

## ⏯️ 1. 播放与暂停

- **快捷键**
  按下 <kbd>Space</kbd>（空格键）。
- **鼠标操作**
  单击视频画面中央区域，或点击控制栏最左侧的 **播放 / 暂停** 按钮。
- **状态指示**
  暂停时画面中心会短暂呈现半透明状态微标，指示当前播控状态。

---

## ⏩ 2. 进度跳转与单帧步进

- **时间轴拖拽**
  在底部进度条上任意单击或按住滑块左右拖动，支持实时缩略图预览（Timeline Thumbnails）。
- **方向键跳转**
  - <kbd>→</kbd>（右方向键）：向前快进 5 秒。
  - <kbd>←</kbd>（左方向键）：向后快退 5 秒。
- **单帧精确定位**
  - 在视频暂停状态下，按下 <kbd>.</kbd>（句号键）可实现 **单帧向前步进**，方便对关键帧进行截图或画面对比。

---

## 🔊 3. 音量调节与静音

- **音量增减**
  - 键盘：按下 <kbd>↑</kbd> 增加音量，按下 <kbd>↓</kbd> 降低音量（步长 5%）。
  - 鼠标滚轮：在视频画面任意区域上下滚动滚轮，或在控制栏音量图标上方滚动。
- **一键静音**
  按下快捷键 <kbd>M</kbd> 或单击音量喇叭图标切换静音状态。

---

## 🚀 4. 倍速播放与音调保持

- **倍速调节**
  在控制栏右侧点击倍速按钮（如 `1.0x`），可快速选择 `0.5x`、`0.75x`、`1.0x`、`1.25x`、`1.5x`、`2.0x` 或自定义倍速。
- **智能音调补偿**
  内置 SoundTouch 专业音频时间伸缩算法，在加速或减速播放时自动校正音高，人声清晰自然，无“花栗鼠”变声失真。

---

## ⌨️ 5. 常用快捷键速查

| 操作动作 | 默认按键 | 说明 |
| :--- | :--- | :--- |
| **播放 / 暂停** | <kbd>Space</kbd> | 切换当前播放与暂停状态 |
| **全屏 / 还原** | <kbd>F</kbd> / <kbd>Enter</kbd> | 切换无边框全屏模式 |
| **退出全屏 / 关闭浮层** | <kbd>Esc</kbd> | 退出全屏或隐藏当前打开的菜单 |
| **快退 / 快进** | <kbd>←</kbd> / <kbd>→</kbd> | 默认步长 5 秒 |
| **音量调节** | <kbd>↑</kbd> / <kbd>↓</kbd> | 增减播放音量 |
| **静音切换** | <kbd>M</kbd> | 一键静音 / 取消静音 |
| **单帧步进** | <kbd>.</kbd> | 暂停时逐帧向前步进 |
| **打开文件** | <kbd>O</kbd> | 呼出打开本地文件对话框 |
| **停止播放** | <kbd>S</kbd> | 停止播放并释放解码资源 |
| **切换播放统计 (OSD)** | <kbd>Tab</kbd> | 显示 / 隐藏实时渲染参数与丢帧监控 |
| **截取当前画面** | <kbd>Ctrl</kbd> + <kbd>S</kbd> | 按照原始分辨率无损保存当前帧为图片 |

> 💡 **提示**：所有快捷键均可在 **设置 → 快捷键** 中自由修改与重置。
