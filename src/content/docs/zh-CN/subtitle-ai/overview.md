# AI 转录与翻译概览

遇到无字幕的海外影视“生肉”、外语讲座录像或外服游戏实况？Kyna Player 内置了开箱即用的 **AI 智能字幕实验室**，将前沿的语音识别（ASR）与大语言模型（LLM）翻译技术无缝整合到播放器中。

---

## ⚡ 核心 AI 工作流 (AI Pipeline)

Kyna Player 的 AI 字幕系统采用高内聚的流水线架构设计，可一键完成从音频提取到双语字幕挂载的全流程：

```
+------------------+     +--------------------+     +--------------------+     +------------------+
| 🔊 视频音频流提取  | ──> | 🎙️ Whisper 本地识别 | ──> | 🌐 LLM 智能语义翻译 | ──> | 💬 实时双语字幕呈现 |
|  (FFmpeg Demux)  |     |   (离线/隐私安全)   |     | (上下文润色/防机翻)  |     |  (同屏对照/导出)  |
+------------------+     +--------------------+     +--------------------+     +------------------+
```

---

## 🌟 核心优势与亮点

### 1. 🔒 100% 本地离线推理，隐私零泄露
- 语音识别（Whisper）完全在你的本地 GPU（CUDA / Vulkan / DirectML）或 CPU 上运行，无需上传任何音频片段，保护个人与商业隐私。

### 2. 🧠 上下文感知翻译（拒绝生硬机翻）
- 传统机翻工具只能逐行机械翻译，极易丢失语境与人称代词。
- Kyna Player 支持接入主流大语言模型（如 DeepSeek、OpenAI GPT-4o、Claude、Ollama 本地模型），结合视频前后文语境与专业术语库，产出媲美专业字幕组的高质量润色译文。

### 3. ⚡ 极速全自动对齐时间轴 (VAD & Timestamp)
- 内置语音活动检测（Silero VAD），能够精准剔除视频中的背景音乐 (BGM)、打斗音效与静音片段，自动切分出呼吸自然的字幕时间段。

## 🚀 快速上手 AI 功能

1. **唤出 AI 面板**：点击控制栏右侧的 `🤖 AI` 图标，或按快捷键 <kbd>Alt</kbd> + <kbd>A</kbd>。
2. **选择任务模式**：
   - **一键转录并翻译**
  从音频识别出原文并立即翻译为目标语言（生成双语字幕）。
   - **仅语音转录**
  仅生成当前音频对应语言的原文字幕。
   - **仅字幕翻译**
  直接翻译已加载的外挂或内嵌字幕文件。
3. **点击“开始生成”**：右下角将显示进度条与预计耗时，完成后自动无缝挂载至当前视频！
