# 大模型字幕翻译

传统的逐句机翻常常忽视上下文语境，导致人称混乱、笑点丢失与俚语误译。Kyna Player 引入了基于**大语言模型（LLM）的智能上下文翻译流水线**，将影视翻译质量推向全新高度。

---

## 🔌 支持的翻译服务引擎

在 **设置 → AI 服务配置** 或侧边栏中，你可以轻松配置以下大模型后端：

| 翻译服务商 / 引擎 | 支持模型举例 | 特色优势 |
| :--- | :--- | :--- |
| **DeepSeek (深度求索)** *(推荐)* | `deepseek-chat`, `deepseek-reasoner` | 极高性价比、中文语境表达极佳、影视台词本地化极强 |
| **OpenAI** | `gpt-4o`, `gpt-4o-mini` | 强大的多语言通用翻译能力与上下文推理 |
| **Anthropic Claude** | `claude-3-5-sonnet` | 极高的文学修养与自然流畅的对白润色 |
| **Ollama (本地私有化)** | `qwen2.5`, `llama3.1`, `gemma2` | 100% 本地运行、免费无限制、断网可用 |
| **自定义兼容端点** | 任意 OpenAI-Compatible API | 支持第三方聚合代理网关或自建 API 端点 |

---

## 🧠 影视上下文与 Prompt 优化引擎

Kyna Player 在向大模型发送翻译请求时，并非简单逐句发送，而是采用了**滑窗上下文批量切分机制**：

```
[ 上一段台词 (提供前情提要) ] + [ 当前待译台词 (重点精译) ] + [ 下一段台词 (预知后续情绪) ]
                                    │
                                    ▼
           大模型结合人物性格、语气情感输出自然对白
```

### 个性化翻译定制选项
- **影视类型偏好**
  可指定片源类型（如 *科幻电影*、*动漫日常*、*医学美剧*、*IT技术教程*），大模型将自动采用匹配的专业术语。
- **自定义专有名词表 (Glossary)**
  支持预设角色姓名、地名、装备译名对照，确保整季追剧人名翻译前后一致。

## 💬 双语对照排版模式

翻译完成后，可一键选择生成的字幕排版形式：

1. **双语上下对照** *(最受欢迎)*：
   - 上排：目标译文（中文字体稍大，醒目易读）。
   - 下排：原文对白（英/日文字体适中，方便对照学习）。
2. **纯译文字幕**：仅保留高质量中文翻译，纯享剧情。
3. **保留并输出为独立双字幕文件**：保存为标准 `.srt` 或 `.ass` 文件供其他设备使用。
