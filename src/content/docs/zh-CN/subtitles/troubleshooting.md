# 字幕常见问题

遇到字幕乱码、不同步或无法正常显示？以下是针对最常见字幕问题的诊断与快速解决办法。

---

## ❓ 常见问题速查与解决方案

### 1. 🔤 字幕出现“口口口”乱码或问号
- **核心原因**
  字幕文件采用了老旧的 `GBK / GB2312 / Big5` 或 `ANSI` 字符编码，而解码器默认使用 `UTF-8`。
- **解决方法**
  1. 打开侧边栏 **字幕面板**。
  2. 在 **文本编码 (Text Encoding)** 下拉菜单中，将 `UTF-8` 手动切换为 `GB18030 / GBK` 或 `Big5`。
  3. 切换后字幕文字将即刻恢复正常中文显示。

---

### 2. ⏳ 字幕越来越快或越来越慢（时间轴渐进式漂移）
- **核心原因**
  视频片源与字幕文件的**原生帧率不一致**（例如片源是 23.976 fps，而字幕是按 25.0 fps 欧洲 PAL 制式时间轴制作的）。
- **解决方法**
  - 在 **字幕设置** 中调整 **字幕帧率适配 (Subtitle FPS)**，将 `25.0 fps` 转换为 `23.976 fps`。
  - 若仅为固定时差（如整体提前了 2 秒），使用快捷键 <kbd>G</kbd> / <kbd>H</kbd> 进行毫秒微调即可。

---

### 3. 🚫 拖入字幕后画面无任何反应
- **排查步骤**
  1. 确认字幕文件扩展名是否为标准格式（`.srt`, `.ass`, `.ssa`, `.vtt`, `.sub`）。
  2. 检查视频画面中是否设置了“隐藏字幕”状态（按下 <kbd>V</kbd> 键重新激活字幕显示）。
  3. 若为纯图形蓝光字幕 (`.sup` / `.pgs`)，检查分辨率缩放设置是否导致字幕位置被裁切在屏幕视口之外。

---

### 4. 🎭 ASS 特效字幕样式变形或显示为普通宋体
- **核心原因**
  压制组在 ASS 字幕中指定了特殊艺术字体（例如特定动漫字体），而你的 Windows 系统尚未安装该字体。
- **解决方法**
  - 将字幕自带的 `.ttf` / `.otf` 字体文件双击安装到 Windows 系统中。
  - 或者在 **设置 → 字幕外观** 中开启 **“回退至默认字体”** 并选择一款易读的中文字体（如微软雅黑或思源黑体）。
