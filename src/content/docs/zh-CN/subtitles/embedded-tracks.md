# 内嵌与双字幕

MKV、MP4 等现代多媒体容器通常封装了多个语言的内嵌字幕轨。Kyna Player 提供了极具创新性的**主副双字幕对照系统**，非常适合外语影视学习、双语字幕对照观影。

---

## 📑 内嵌字幕轨识别与切换

当播放包含内嵌字幕的媒体文件时：

1. **字幕侧边栏面板**：点击控制栏右侧字幕图标或按快捷键 <kbd>Alt</kbd> + <kbd>S</kbd> 打开字幕列表。
2. **右键快速选择**：在画面上右键单击 → **字幕 (Subtitles)** → **字幕轨道**。
3. **快捷键快速轮换**：按下 <kbd>V</kbd> 键在所有可用字幕轨与“关闭字幕”之间快速轮转。

播放器会自动识别并列出字幕轨的详细元数据，例如：`[1] 简体中文 (ass)`、`[2] 繁體中文 (srt)`、`[3] English (pgs)`。

---

## 👥 主副双字幕系统 (Dual Subtitles)

在学习外语或观看生肉/双语片源时，你可以同时指定两个字幕轨道分别作为**主字幕 (Primary)** 和 **副字幕 (Secondary)**：

```
+-------------------------------------------------------------+
|                                                             |
|                         [ 视频画面 ]                        |
|                                                             |
|                                                             |
|           [副字幕] I think we should go right now.          |
|           [主字幕] 我觉得我们应该立刻出发。                  |
+-------------------------------------------------------------+
```

### 如何配置双字幕
1. 打开侧边栏 **字幕面板**。
2. 在主字幕下拉框中选择你偏好的母语（如中文）。
3. 在副字幕下拉框中选择想要对照的原语言（如英语/日语）。
4. **独立位置与字号**：系统允许主字幕与副字幕设置不同的字号、颜色和垂直上下间距，避免画面文字相互遮挡重叠。

---

## 🎯 默认首选语言规则 (Auto Match)

厌倦了每次打开视频都要手动选中文？在 **设置 → 字幕偏好** 中配置：
- **首选字幕语言代码**
  输入 `zh, chi, chn, sc, tc`。
- **次选字幕语言代码**
  输入 `en, eng`。
- 播放器加载新视频时，将按照规则自动激活最匹配的字幕轨，完全无需手动干预。

## 📦 支持的字幕格式

| 字幕格式 | 类型与特性 | Kyna Player 渲染支持 |
| :--- | :--- | :--- |
| **ASS / SSA** | 高级特效字幕，支持复杂样式、定位、描边与动画 | 完整 libass 高性能硬件加速渲染 |
| **SRT** | 纯文本字幕，轻量通用 | 完整支持自定义样式与字体 |
| **VTT (WebVTT)** | Web 流媒体常用字幕格式 | 完整支持 |
| **PGS / SUP** | 蓝光原盘图形点阵字幕 | 完整无损解析与图形图层渲染 |
| **DVB / Teletext** | 广播电视内嵌字幕 | 完整支持 |
