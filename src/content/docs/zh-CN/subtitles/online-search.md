# 在线字幕搜索

当下载的电影或剧集没有中文字幕时，无需打开浏览器反复搜索下载解压。Kyna Player 集成了**在线字幕一键检索与自动挂载引擎**。

---

## 🔍 在线搜索与加载流程

```
[ 播放生肉视频 ] ──> [ 点击在线搜索字幕 ] ──> [ 哈希精准匹配 ] ──> [ 一键下载挂载 ]
```

### 1. 触发在线搜索
- 快捷键：按下 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>。
- 鼠标操作：打开侧边栏 **字幕面板**，点击顶部的 **“🌐 在线搜索字幕”** 按钮。

### 2. 双重智能匹配机制
- **文件哈希比对 (Hash Match)**
  计算当前视频文件头尾的特征指纹，在字幕库中精确锁定专为该压制版本制作的字幕，时间轴 100% 严丝合缝。
- **标题模糊检索 (Title Fallback)**
  若哈希未命中，引擎会自动解析文件名中的影片名称、季集数（如 `S01E05`）、压制组信息并进行语义检索。

### 3. 选择与一键下载
- 搜索结果列表中会清晰展示：语言标识（🇨🇳 简中 / 🇹🇼 繁中 / 🇺🇸 英文等）、文件格式（`.ass` / `.srt`）、发布来源与匹配度。
- 单击目标条目，播放器将在 1 秒内完成下载、解密并**即时应用到当前播放画面**，无需重启或重新打开文件。

---

## ⚙️ 字幕服务源与存储偏好

在 **设置 → 字幕服务** 中，你可以个性化配置：

- **字幕提供商源配置**
  - 支持启用/禁用主流开源字幕数据库（OpenSubtitles、Shooter 射手网、Subscene、Assrt 等）。
  - 支持配置 OpenSubtitles 个人 API 账户（获取更高下载限额）。
- **字幕保存路径策略**
  - **保存在视频同级目录** *(推荐)*：将下载的字幕重命名为 `视频名.zh-CN.srt` 存放在视频同目录下，便于长期保留与离线使用。
  - **保存在临时缓存目录**
  仅临时加载，不污染媒体库文件夹。
