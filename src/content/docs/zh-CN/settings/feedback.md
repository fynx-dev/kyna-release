## 📋 提交高质量 Bug 报告指南

为了帮助开发团队以最快速度定位并修复问题，建议在反馈时附带以下信息：

```
1. 软件版本：Kyna Player v1.0.0 (x64)
2. 系统环境：Windows 11 23H2 / RTX 4070 (驱动版本: 560.xx)
3. 问题描述：播放特定 10-bit AV1 视频时开启 Anime4K 出现卡顿
4. 复现步骤：
   - 打开视频 sample.mkv
   - 按 Alt+V 开启 Anime4K Mode A
   - 播放 10 秒后出现掉帧
5. 附件：附带媒体属性文本 (Ctrl+I) 与 kyna_player.log 日志
```

---

## 📄 如何获取运行日志 (Log)

1. 打开 **设置 → 通用 (General)**。
2. 点击 **“📂 打开 AppData 目录”**。
3. 进入 `logs/` 文件夹，即可找到名为 `kyna_player.log` 的诊断日志。

> [!NOTE]
> **🔒 隐私承诺**：Kyna Player 的运行日志仅包含编解码器调度、着色器编译错误与时间戳性能统计，**绝不会收集或上传任何个人隐私、浏览历史或视频画面内容**。
