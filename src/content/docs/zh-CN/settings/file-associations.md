文件关联让你可以在 Windows 资源管理器中更方便地使用 Kyna Player 打开媒体文件。

## 选择关联格式

打开“设置 → 文件关联”，勾选希望由 Kyna Player 注册的媒体扩展名。应用设置后，这些格式会出现在 Windows 的“打开方式”选项中。

> [图片占位：文件关联设置页]
>
> 建议文件名：`file-associations-settings.png`

文件关联不会强制改变所有格式的双击默认应用。若要把某个格式的双击行为改为 Kyna Player，请在 Windows 的默认应用设置中完成选择。

## 资源管理器右键菜单

启用“添加到文件右键菜单”后，Windows 资源管理器会显示“用 Kyna Player 打开”命令。它适合偶尔用 Kyna Player 打开文件，而无需把该格式设为系统默认。

## 修改后未生效

请先点击“应用”或“保存”，再关闭并重新打开资源管理器窗口。Windows 可能会缓存文件图标和默认应用显示；如仍未更新，请在 Windows 设置中确认该扩展名的默认应用。
