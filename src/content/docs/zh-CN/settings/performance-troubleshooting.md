# 性能调优与排错

遇到 4K 超清播放掉帧、黑屏、音画不同步或 HDR 色彩异常？请参考本篇实战排查指南迅速恢复最佳播放状态。

---

## 🛠️ 常见故障诊断与解决

### 1. 📺 播放 4K/8K 高码率视频出现卡顿、掉帧
- **排查 1：核显/独显调度问题（多显卡笔记本）**
  - 双显卡笔记本可能错误调用了低功耗核显。
  - 打开 **Windows 设置 → 系统 → 显示 → 图形**，找到 `Kyna Player`，将首选项指定为 **“高性能 (NVIDIA / AMD 独立显卡)”**。
- **排查 2：确认已启用 GPU 硬件加速**
  - 在 **设置 → 视频** 中，确保解码器设置为 **“Direct3D 11 (D3D11VA)”**。
- **排查 3：关闭过重的实时超分辨率滤镜**
  - 若正在运行 2x Anime4K 或 DLSS 5 增强，尝试切换为轻量预设（Mode Fast）或暂时关闭滤镜。

---

### 2. 🟢 画面黑屏、绿屏，但声音正常播放
- **核心原因**
  显卡驱动的硬件解码单元对某种非标准编码参数解析失败。
- **解决方法**
  1. 在画面上右键单击 → **视频** → **硬件解码**。
  2. 临时切换为 **“CPU 软件解码 (Software)”**，画面将立即恢复正常。
  3. 前往显卡官网（NVIDIA / AMD / Intel）将显卡驱动更新至最新 WHQL 正式版。

---

### 3. 🌈 HDR 视频在普通显示器上画面发灰、过曝
- **核心原因**
  HDR BT.2020 色彩未正确转换为 SDR BT.709 目标色域。
- **解决方法**
  - 进入 **设置 → 画面调节**，确保勾选 **“启用 SDR 色调映射 (Tonemapping)”**。
  - 算法推荐选择 `Reinhard` 或 `Mobius`，画面色彩将立刻恢复饱满通透。

---

### 4. 🔊 蓝牙耳机声音滞后于口型（音画不同步）
- **解决方法**
  - 使用音频微调快捷键 <kbd>Ctrl</kbd> + <kbd>[</kbd> 将音频提前 100ms ~ 200ms，即可瞬间抵消蓝牙协议本身的传输延迟。
