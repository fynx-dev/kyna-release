# 设置中心

Kyna Player 提供了模块化、层次清晰的偏好设置中心。你可以根据个人硬件配置与观影习惯，深度定制播放器的所有行为。

---

## 🚪 打开设置面板

- **快捷键**
  按下 <kbd>F2</kbd> 或 <kbd>Ctrl</kbd> + <kbd>,</kbd>。
- **界面入口**
  点击控制栏右下角的 `⚙️ 设置` 按钮，或在主画面右键菜单选择 **“偏好设置”**。

---

## 📑 设置分类与功能导航

```
+-------------------------------------------------------------+
| ⚙️ 设置 (Settings)                                          |
|                                                             |
| [ 🏠 通用 (General) ] ── 语言切换 / 窗口行为 / 历史容量 / AppData |
| [ ⏯️ 播放 (Playback) ] ─ 默认倍速 / 自动连播 / Seek 步进跨度  |

```

## 🛠️ 各标签页核心配置速览

### 1. 🏠 通用 (General)
- **界面语言 (UI Language)**
  简体中文、English、繁體中文、日本語、한국어 实时热切换。
- **窗口行为**
  记忆上次窗口大小与退出位置、单实例运行（阻止重复打开多个窗口）。
- **应用数据管理**
  提供“打开 AppData 数据目录”快捷按钮，方便快速备份配置与清理缓存。

### 2. 📺 视频与渲染 (Video & Rendering)
- 配置 Direct3D 11/12 硬件加速渲染器、HDR 色调映射算法、Anime4K / DLSS 5 默认增强预设。

### 3. 💬 字幕与 AI (Subtitles & AI)
- 自定义字幕渲染字体、大小、边框阴影、首选双字幕语言、Whisper 本地模型路径与大模型 API Key。

### 4. ⌨️ 快捷键 (Hotkeys)
- 支持为所有播放动作（快进、截屏、音量、滤镜）重新绑定自定义按键与鼠标滚轮手势。

### 5. 🔗 文件关联 (File Associations)
- 一键将 `.mp4`、`.mkv`、`.avi` 等视频格式注册关联至系统，并在 Windows 右键菜单中显示友好的 `Kyna Player` 启动项。
