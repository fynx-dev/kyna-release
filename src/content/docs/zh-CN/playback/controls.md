# 播控与单帧步进

Kyna Player 提供了极致平滑与响应迅速的播放状态控制。无论你是日常观影追剧，还是需要逐帧分析视频、截取精准画面的专业用户，都能通过鼠标或键盘快捷键轻松掌控。

---

## 🎮 基础播控功能

### 1. 播放与暂停 (Play / Pause)
- **快捷键**
  <kbd>Space</kbd>（空格键）
- **鼠标操作**
  单击底部控制栏的 `▶ / ❚❚` 图标，或直接在视频画面中央左键单击（可设置）。
- **无缝响应**
  得益于硬件多线程渲染管线，暂停与恢复几乎零延迟，音频与视频时刻保持绝对音画同步。

### 2. 停止播放 (Stop)
- **快捷键**
  <kbd>S</kbd> 或 <kbd>Ctrl</kbd> + <kbd>S</kbd>
- **功能效果**
  完全停止当前媒体的解码并释放底层流缓存，播放进度重置为 `00:00:00`，画面回到初始待机态。

## 🎞️ 单帧步进与逐帧回退 (Frame Stepping)

在排查视频细节、截取无拖影的超清静态剧照、或分析动画原画动作时，单帧步进功能极为实用：

| 功能 | 快捷键 | 详细说明 |
| :--- | :--- | :--- |
| **单帧前进** (Frame Forward) | <kbd>.</kbd> (句号) / <kbd>E</kbd> | 视频暂停时向前推进精确的一帧画面 |
| **单帧后退** (Frame Backward) | <kbd>,</kbd> (逗号) | 视频暂停时向后回退精确的一帧画面 |

> [!TIP]
> 当视频处于播放状态时按下单帧快捷键，播放器会自动先进入暂停状态，然后再执行单帧移动，防止画面连续闪烁。

## ⏩ 倍速播放与变速变调 (Speed Control)

无论是快速浏览长视频还是精听外语听力，Kyna Player 提供高质量的音调保真变速算法（音频变速不失真变尖）：

- **预设档位快速切换**
  - 点击控制栏右侧的倍速按钮（如 `1.0x`），在下拉菜单中直接选择 `0.5x`、`0.75x`、`1.0x`、`1.25x`、`1.5x`、`2.0x`。
- **键盘平滑微调**
  - **加速**
  <kbd>]</kbd> 或 <kbd>C</kbd>（每次增加 0.1x）
  - **减速**
  <kbd>[</kbd> 或 <kbd>X</kbd>（每次减少 0.1x）
  - **重置为原速 (1.0x)**
  <kbd>Backspace</kbd> 或 <kbd>Z</kbd>

## 🔊 音量控制与超额增益 (Volume & Boost)

- **常规音量调节**
  - 滚动鼠标滚轮：上下滚动每次调节 `5%`。
  - 键盘方向键：<kbd>↑</kbd> 增加音量，<kbd>↓</kbd> 减小音量。
- **一键静音 (Mute)**
  - 按下 <kbd>M</kbd> 键快速静音或恢复此前音量。
- **200% 超额声音增益**
  - 遇到录制音量过小的老旧视频或电影对白，可将音量滑条推至 100% 以上（最高支持 200% 软件无损放大）。
