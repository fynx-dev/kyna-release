**Kyna Player** 为不同观影场景提供了灵活的视窗模式与强大的硬件级性能监控功能。

---

## 🖥️ 1. 全屏沉浸模式

### 进入与退出全屏
- **快捷键**
  按下快捷键 <kbd>F</kbd> 或 <kbd>Enter</kbd> 快速切换全屏。
- **鼠标双击**
  在视频画面任意空白区域双击鼠标左键。
- **界面按钮**
  点击控制栏右下角的全屏图标。
- **退出全屏**
  按下 <kbd>Esc</kbd> 或再次按下 <kbd>F</kbd> / 双击画面即可恢复窗口模式。

### 全屏沉浸体验特性
- ✨ **智能自动隐藏**
  在全屏状态下，鼠标静止 2 秒后，标题栏与底部控制栏将自动平滑淡出，呈现无干扰的纯净画面。
- 🖱️ **即时唤醒**
  轻微晃动鼠标，播控栏与进度条将即刻渐显。
- 🚫 **禁用锁屏休眠**
  视频全屏播放期间，播放器会自动阻止 Windows 系统进入锁屏或息屏睡眠状态。

## 🪟 2. 迷你小窗模式 (画中画)

当你需要在处理文档、浏览网页或多任务办公的同时观看视频时，可开启 **迷你小窗模式**：

- **进入方式**
  点击播放器标题栏的 **迷你模式** 按钮（或自定义快捷键）。
- **始终置顶 (Always on Top)**
  迷你小窗自动保持在所有 Windows 应用窗口的最前端。
- **极简控制**
  悬停小窗时浮现基础播控（播放/暂停、快进快退、音量、关闭/还原）。
- **自由缩放与贴边**
  支持拖拽小窗边缘自由调整尺寸，窗口贴合屏幕边缘时支持自动吸附。

## 📊 3. 实时播放统计 (OSD Panel)

Kyna Player 内置了专业级的实时性能诊断面板，方便进阶用户与影音发烧友查看视频流的底层渲染参数。

### 开启与关闭
- 按下快捷键 <kbd>Tab</kbd> 即可在画面左上角开启或关闭 **实时统计面板**。

### 统计指标详解

```text
================== Kyna Player Statistics ==================
Resolution:    3840x2160 (Source 4K) -> 3840x2160 (Display)
Render FPS:    59.94 fps (Target: 60.00 fps)  Dropped: 0 frames
Decoder:       Direct3D 11 Video Acceleration (D3D11VA - NVDEC)
Color Space:   BT.2020 / HDR10 (PQ) -> SDR Rec.709 Tone Mapping Active
Audio:         FLAC 5.1 Surround (48.0 kHz / 24-bit / 6 Channels)
Filter:        DLSS 5 Neural Reconstruction (Latency: 4.2ms / Budget: 16.6ms)
============================================================
```

- 🎞️ **分辨率与缩放**
  显示原始视频宽高、画面实际渲染尺寸以及当前的缩放倍率。
- ⚡ **渲染帧率与丢帧检测**
  实时计算实际呈现 FPS，监测显卡丢帧（Dropped Frames）情况。
- 🛠️ **解码管线**
  指示当前采用的是 D3D11 硬件加速解码还是 CPU 软解。
- 🌈 **色彩格式与 HDR 状态**
  显示当前源色彩空间（Rec.709 / DCI-P3 / BT.2020）、传输特性（SDR / PQ / HLG / Dolby Vision）以及色调映射（Tone Mapping）是否激活。
- 🔊 **音频流参数**
  显示当前输出音轨的编码格式、采样率、位深及声道拓扑。
- 🧠 **AI 滤镜耗时监控**
  若开启了 DLSS 5 或 Anime4K，面板会实时显示神经网络推断耗时（ms）与实时时间预算利用率。
