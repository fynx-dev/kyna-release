# 进度条与精确定位

在观看长视频或定位精彩片段时，高效准确的时间轴导航能够极大提升体验。Kyna Player 内置多级快进快退机制、悬停缩略图预览与帧级精确定位引擎。

---

## 🎯 时间轴导航与交互

### 1. 点击与拖拽快速定位
- **鼠标单点**
  直接点击进度条上的任意位置，播放器瞬间跳转到对应时间戳。
- **按住拖拽**
  在时间轴上按住鼠标左键并左右拖动，画面中央会弹出当前定位时间的大号 HUD 浮窗提示，松开按键即刻开始播放。

### 2. 悬停时间与缩略图预览
- 将鼠标移动到时间轴上方（无需点击），鼠标上方将弹出当前指向位置的精确时间点（`hh:mm:ss`）以及由后台高速解码生成的**关键帧画面缩略图**，助你瞬间确认剧情发展。

---

## ⏩ 多级快进与快退快捷键 (Seeking)

Kyna Player 支持根据不同使用需求，进行微调或大跨度跳转：

| 操作档位 | 跳转跨度 | 默认快捷键 | 推荐使用场景 |
| :--- | :--- | :--- | :--- |
| **小步微跳** | **±5 秒** | <kbd>→</kbd> / <kbd>←</kbd> | 听清一句错过的台词、短视频回看 |
| **中步快进** | **±30 秒** | <kbd>Ctrl</kbd> + <kbd>→</kbd> / <kbd>←</kbd> | 跳过简短广告或无声片段 |
| **大步跨越** | **±60 秒** | <kbd>Shift</kbd> + <kbd>→</kbd> / <kbd>←</kbd> | 快速跳过片头片尾曲 (OP/ED) |
| **百分比跳转** | **0% ~ 90%** | 数字键 <kbd>0</kbd> ~ <kbd>9</kbd> | 按 <kbd>5</kbd> 跳转至视频刚好一半处 |

## 🔬 关键帧定位 vs 精确帧定位

Kyna Player 在底层解码器中采用了智能 Seeking 策略：

```
[I 关键帧 1] ---- (B/P 预测帧) ---- [I 关键帧 2] ---- (B/P 预测帧) ---- [I 关键帧 3]
       │                                     ▲
       └────────────── 极速定位 ──────────────┘
```

1. **快速关键帧定位 (Fast Seeking)**：
   - 默认模式下，播放器会直接寻址到距离目标时间最近的关键帧 (I-Frame)，实现零等待、不卡顿的极致平滑拖拽体验。
2. **绝对精确帧定位 (Exact Frame Seeking)**：
   - 当使用单帧步进或暂停状态下的精细操作时，渲染管线会自动从最近的关键帧快速补齐解码中间的预测帧 (P/B 帧)，确保画面与时间戳绝对一致。

## 📡 特殊流媒体的定位限制

并非所有媒体格式都支持任意快进快退，遇到无法拖动时请留意媒体类型：

> [!NOTE]
> - **实时直播流 (Live Streams)**：如 `rtmp://`、`rtsp://` 或 HTTP-FLV 直播流，因为数据是实时产生的，不支持向前快进或任意跳转，进度条将显示为直播锁定状态。
> - **正在写入的未完成文件**：例如正在录制中的 OBS 视频文件，由于尾部索引未完全封包，Seek 范围仅限已写入并索引的数据段。
