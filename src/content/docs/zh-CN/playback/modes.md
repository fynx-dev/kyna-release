# 循环与播放模式

Kyna Player 提供了丰富的播放流程控制策略，无论是整季追剧自动连播、单曲/教学视频反复循环学习，还是音乐库随机播放，都能一键随心切换。

---

## 🔀 四大核心播放模式

点击底部控制栏右侧的**循环模式图标**，或在播放列表面板中点击模式切换按钮，可在以下模式中循环切换：

| 模式图标 | 播放模式 | 行为逻辑与说明 | 推荐使用场景 |
| :---: | :--- | :--- | :--- |
| 🔁 | **列表循环 (List Loop)** | 当前列表所有项目播放完毕后，自动从头开始循环播放。 | 追剧连播、长视频串联播放 |
| 🔂 | **单曲循环 (Single Loop)** | 当前文件播放结束后，立即从头重新播放同一个文件。 | 舞蹈/乐器教学视频、单曲音乐 |
| 🔀 | **随机播放 (Shuffle)** | 随机抽取列表中的曲目进行播放，不重复播放已放内容。 | 个人音乐库、播客、MV 派对播放 |
| ➡️ | **顺序播放 (Sequential)** | 从当前项依次播到列表末尾，播放完最后一个文件后自动停止。 | 单集电影观看、定时停止 |

---

## ⏭️ 上一项与下一项切换

当播放列表中有多个媒体时，你可以随时进行项目跳转：

- **下一项 (Next Track)**
  - 快捷键：<kbd>PageDown</kbd> 或 <kbd>N</kbd>
  - 点击控制栏的 `⏭` 按钮
  - 若处于列表循环模式，在最后一项按下下一项将自动跳至第一项。
- **上一项 (Previous Track)**
  - 快捷键：<kbd>PageUp</kbd> 或 <kbd>P</kbd>
  - 点击控制栏的 `⏮` 按钮
  - 若当前文件已播放超过 3 秒，按一次通常会重置当前文件至起点，短时间内连按两次则跳至上一个文件。

## 📺 连续剧智能自动连播 (Auto Play Next)

当你将包含多集电视剧、动漫剧集的文件夹拖入播放器时：
1. **自动排序**：Kyna Player 采用**自然数排序法（Natural Sort）**（例如 `EP01, EP02, ..., EP10`），杜绝乱序。
2. **无缝衔接**：当前集播放到达末尾时，底层解码引擎会自动预加载下一集元数据，实现秒级切换与连续播放。
3. **断点记忆**：切换剧集时，系统会自动记录上一集的播放进度，方便下次返回时直接续播。

## 💡 使用小贴士

> [!TIP]
> - **单视频快速循环**：如果你仅打开了一个独立的视频文件（播放列表仅 1 项），切换为 🔁 或 🔂 模式均能实现该视频的无限循环播放。
> - **快捷模式切换**：按下 <kbd>Ctrl</kbd> + <kbd>R</kbd> 可以不打开菜单直接快速在四种循环模式间轮换。
