# 搜索、排序与净化

当播放列表中包含上百集动画或上千首音乐时，如何快速找到目标曲目并保持正确的播放顺序？

---

## ⚡ 列表即时搜索与过滤

- 在播放列表顶部搜索栏中输入关键字（如 `05`、`剧场版`、`Live` 或拼音首字母）。
- 列表瞬间进行**毫秒级动态过滤**，仅显示符合条件的条目。
- 按 <kbd>Esc</kbd> 键一键清空搜索框并恢复完整列表展示。

---

## 🔢 自然数智能排序 (Natural Sort)

传统软件在对文件名排序时常常会出现 `1, 10, 11, 2, 3...` 的尴尬反常识乱序。

Kyna Player 内置了先进的**自然数排序引擎（Natural Order Sorting）**：

```
传统 ASCII 排序 ❌ :  Episode 1.mp4  ->  Episode 10.mp4 ->  Episode 2.mp4
Kyna 自然数排序 ✅ :  Episode 1.mp4  ->  Episode 2.mp4  ->  Episode 10.mp4
```

### 多种排序维度
点击列表顶部的 **“排序”** 按钮，可按不同规则重排：
- **按文件名 (升序 / 降序)**
- **按修改时间 / 添加时间**
- **按文件大小**
- **随机打乱 (Shuffle Once)**

---

## ✨ 智能文件名净化 (Clean Title)

压制组发布的文件名往往带有大量技术标签，例如：
`[VCB-Studio] Frieren Beyond Journey's End [01][Ma10p_1080p][x265_flac].mkv`

开启播放列表的 **“智能文件名净化”** 开关后：
- 播放器会自动识别并折叠压制组、编码格式、音频规格等冗余信息。
- 列表中精简展示为：`葬送的芙莉莲 - 第 01 集`。
- 视觉界面整洁优雅，剧集进度一目了然！
