# 播放列表管理

Kyna Player 提供了标准且强大的播放列表管理功能，支持将追番列表、音乐歌单、教学课程整理保存为通用的播放列表文件。

---

## ➕ 新建与管理播放列表

1. **唤出播放列表面板**：按快捷键 <kbd>F3</kbd> 或在控制栏右侧点击 `📑 播放列表` 图标。
2. **新建空白列表**：点击播放列表顶部的 `➕ 新建`，清空当前临时队列并开启全新的媒体清单。
3. **添加项目**：点击 `添加文件` 或直接从 Windows 文件资源管理器将视频/音频拖入列表中。
4. **调整播放次序**：按住鼠标左键拖动列表项即可上下自由拖拽排序。

---

## 💾 保存与导出播放列表 (Export M3U8)

想要将精心整理的几十集追剧列表或无损音乐清单长期保存？

- **保存播放列表**
  点击列表顶部的 **“💾 保存 / 另存为”** 按钮。
- **通用格式支持**
  - **M3U8 (UTF-8 编码)** *(推荐)*：完整支持中文字符、特殊符号与日韩文文件名，避免跨设备乱码。
  - **M3U**
  传统标准播放列表格式。
- **相对路径 vs 绝对路径**
  默认使用相对路径保存。若将 `.m3u8` 文件与视频放在同一移动硬盘或文件夹中，复制到其他电脑依然能完美直接播放。

---

## 📂 加载与打开播放列表

- **直接打开**
  双击任意 `.m3u` / `.m3u8` 文件（若已关联 Kyna Player），自动载入并从第一项开始播放。
- **拖拽导入**
  将播放列表文件直接拖入 Kyna Player 窗口。
- **追加模式**
  按住 <kbd>Ctrl</kbd> 拖入文件时，系统会将新项目追加到现有列表末尾，而不是覆盖当前列表。
