# 文件夹批量导入

当下载了整季电视剧、动漫番剧或整张无损音乐专辑时，无需逐个文件挑选。Kyna Player 提供了极速的**多层文件夹扫描与批量导入引擎**。

---

## 🚀 导入方式与操作

```
[ 本地剧集文件夹 (包含多集视频、海报、nfo) ] ── (拖入 Kyna Player) ──> [ 纯净视频播放列表 ]
```

1. **直接拖拽文件夹**：从桌面或资源管理器中选中一个或多个文件夹，直接拖入 Kyna Player 窗口。
2. **菜单导入**：在主界面点击 **文件 → 打开文件夹...**（快捷键 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd>），选择目标目录。

---

## 🔍 智能过滤与递归扫描规则

批量扫描时，Kyna Player 会自动执行智能预处理：

- **自动过滤杂质文件**
  - 自动保留所有受支持的视频（`.mp4`, `.mkv`, `.avi`, `.mov`, `.flv`, `.ts`, `.webm`, `.wmv` 等）与音频（`.flac`, `.mp3`, `.m4a`, `.wav`, `.aac`, `.dsd` 等）。
  - 自动忽略海报图片（`.jpg`, `.png`）、元数据（`.nfo`, `.xml`）、迅雷种子文件（`.torrent`）与日志文件。
- **递归扫描子目录 (Recursive)**
  - 若文件夹内包含子文件夹（如 `Season 1/`、`Season 2/`、`CD1/`、`CD2/`），播放器将自动向下深入扫描所有子目录并将音视频按层次汇总。
- **自动挂载同名外挂字幕**
  - 扫描视频的同时，若发现同级目录下存在同名的 `.srt` / `.ass` 字幕，自动完成静默关联。
