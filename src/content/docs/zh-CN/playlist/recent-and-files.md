# 播放历史与文件

Kyna Player 提供了贴心的历史记录管理与本地文件联动功能，方便你快速重温精彩内容或整理本地磁盘。

---

## 📜 最近播放历史 (Recent History)

在播放列表顶部的标签页中切换至 **“最近播放”**：

- **断点记忆标记**
  每个条目右侧均清晰记录了上次退出的时间点（例如 `已播放至 45:12 (68%)`）。
- **一键断点续播**
  双击历史条目，播放器瞬间载入视频并精准无缝跳转至上次离开的帧位置。
- **历史记录容量与隐私保护**
  - 在 **设置 → 通用** 中可自定义历史记录保存条数（默认 50 条）。
  - 点击底部的 **“清空历史记录”** 可彻底抹除所有观影痕迹，保护个人隐私。

---

## 🗂️ 列表项操作与文件管理

在播放列表或最近历史的任意条目上右键单击，可调出上下文功能菜单：

| 功能操作 | 快捷键 | 详细说明 |
| :--- | :--- | :--- |
| **打开文件所在位置** | <kbd>Ctrl</kbd> + <kbd>E</kbd> | 在 Windows 文件资源管理器中高亮选中该文件。 |
| **从列表中移除** | <kbd>Delete</kbd> | 仅从当前播放队列中移除，**不会删除磁盘上的物理文件**。 |
| **移至回收站 (物理删除)** | <kbd>Shift</kbd> + <kbd>Delete</kbd> | 将看完的视频文件直接发送到 Windows 系统回收站，释放磁盘空间。 |
| **复制文件路径** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | 复制文件的完整绝对路径至剪贴板。 |
| **查看媒体属性** | <kbd>Ctrl</kbd> + <kbd>I</kbd> | 直接打开该文件的编码与参数诊断面板。 |
