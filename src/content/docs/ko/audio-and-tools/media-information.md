# 미디어 속성 및 진단

상세 인코딩 정보와 하드웨어 디코딩 가동 현황을 한눈에 확인할 수 있습니다.

---

## 🔍 미디어 정보 열기

- **단축키**
  <kbd>Ctrl</kbd> + <kbd>I</kbd> 또는 <kbd>Shift</kbd> + <kbd>I</kbd>
- **메뉴**
  우클릭 → **도구** → **미디어 정보**

---

## 📊 상세 진단 항목

- **컨테이너 정보**
  포맷(`.mkv`, `.mp4` 등), 크기, 전체 비트레이트.
- **비디오 스트림**
  코덱(`HEVC`, `AV1`, `H.264`), 해상도(`3840x2160`), FPS, 색공간(`BT.2020 10-bit`), HDR 표준(`HDR10`, `Dolby Vision`).
- **오디오/자막 스트림**
  채널 레이아웃, 샘플링 레이트, 언어 태그.
- **실시간 진단**
  동작 중인 디코더(`D3D11VA - NVIDIA NVDEC`), 실시간 비트레이트 그래프, 드롭 프레임 카운터.
