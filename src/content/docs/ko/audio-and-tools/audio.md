# 오디오 트랙 및 싱크

서라운드 사운드 패스스루, 다중 오디오 트랙 전환, 밀리초 단위 오디오 싱크 보정을 지원합니다.

---

## 🎧 오디오 트랙 선택

- **단축키**
  <kbd>A</kbd> 또는 <kbd>Ctrl</kbd> + <kbd>A</kbd>
- **상세 메타데이터**
  언어, 채널 구성(`5.1ch`, `7.1ch`, `Stereo`), 코덱(`DTS-HD MA`, `TrueHD Atmos`, `FLAC`, `AAC`) 표시.

---

## 🎛️ 출력 장치 및 다운믹싱

- **독립 출력 장치**
  시스템 전체 사운드에 영향 없이 플레이어 소리만 헤드폰이나 USB-DAC로 출력.
- **HRTF 공간 다운믹싱**
  5.1ch / 7.1ch 서라운드를 2채널 헤드폰에 자연스럽게 다운믹스하여 센터 대사를 선명하게 재현.
- **비트스트림 패스스루**
  AV 리시버로 HDMI / 광출력을 통해 원본 비트스트림 전송.

---

## ⏱️ 오디오 싱크 동기화

| 동작 | 단축키 | 설명 |
| :--- | :--- | :--- |
| **오디오 100ms 지연** | <kbd>Ctrl</kbd> + <kbd>]</kbd> | 화면보다 소리가 먼저 나오는 경우 |
| **오디오 100ms 앞당김** | <kbd>Ctrl</kbd> + <kbd>[</kbd> | 소리보다 화면이 먼저 나오는 경우 (블루투스 지연 등) |
| **싱크 리셋** | <kbd>Ctrl</kbd> + <kbd>\</kbd> | 오디오 딜레이를 0ms로 초기화 |
