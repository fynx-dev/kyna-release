# 스크린샷 및 캡처

영화의 명장면이나 애니메이션의 아름다운 컷을 원본 해상도 무손실 이미지로 즉시 저장할 수 있습니다.

---

## ⚡ 캡처 모드 및 단축키

| 동작 | 단축키 | 설명 |
| :--- | :--- | :--- |
| **일반 캡처** *(추천)* | <kbd>Ctrl</kbd> + <kbd>S</kbd> / <kbd>F5</kbd> | **자막 없는** 순수 원본 해상도 프레임 저장. |
| **자막 포함 캡처** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 화면에 표시된 자막을 포함하여 캡처. |
| **클립보드 복사** | <kbd>Ctrl</kbd> + <kbd>C</kbd> | 파일 생성 없이 클립보드에 바로 복사. |

---

## 📂 포맷 및 네이밍 규칙

- **이미지 포맷**
  무손실 PNG, 고품질 JPEG, WebP.
- **파일명 템플릿**
  `{title}_{time}_{index}.png` (예: `Inception_01-24-36_001.png`).
- **저장 위치**
  기본값 `%USERPROFILE%\Pictures\KynaPlayer\`. 알림 토스트 클릭 시 폴더로 바로 이동.
