# 온라인 자막 검색

브라우저를 열 필요 없이 Kyna Player 내에서 원클릭으로 최적의 자막을 검색하여 즉시 적용할 수 있습니다.

---

## 🔍 검색 및 다운로드 과정

1. **검색 실행**: <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>를 누르거나 자막 드로어의 **"🌐 온라인 자막 검색"**을 클릭합니다.
2. **이중 매칭**:
   - **해시 매칭**
  영상 파일 고유 체크섬을 통해 싱크가 100% 일치하는 릴리즈 자막을 탐색.
   - **제목 검색**
  해시가 없을 경우 영화 제목이나 회차(`S01E05`)로 자동 검색.
3. **원클릭 적용**: 검색 결과에서 원하는 자막을 클릭하면 1초 만에 다운로드되어 즉시 화면에 반영됩니다.
