# 자막 문제 해결

자막 관련 주요 문제와 해결 방법을 정리했습니다:

---

## ❓ 자주 묻는 질문 및 해결책

### 1. 🔤 자막이 '□□□'나 특수문자로 깨져 나오는 경우
- **원인**
  자막 파일이 `UTF-8`이 아닌 `EUC-KR`, `CP949`, `GBK` 등으로 인코딩되어 있음.
- **해결책**
  자막 드로어의 **텍스트 인코딩** 메뉴에서 해당 인코딩을 직접 선택하십시오.

### 2. ⏳ 재생 시간이 지날수록 자막 싱크가 점점 어긋나는 경우
- **원인**
  영상 프레임레이트(23.976 fps)와 자막 기준 프레임레이트(25.0 fps 등)가 다름.
- **해결책**
  자막 설정에서 **자막 프레임레이트**를 변경하거나 <kbd>G</kbd> / <kbd>H</kbd> 단축키로 미세 조절하십시오.

### 3. 🎭 ASS 특수 폰트가 적용되지 않는 경우
- **해결책**
  해당 폰트를 Windows에 설치하거나 자막 설정의 "기본 폰트로 대체"를 켜십시오.
