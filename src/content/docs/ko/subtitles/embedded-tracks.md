# 내장 자막 및 듀얼 자막

MKV나 MP4에 여러 언어의 자막이 포함된 경우, Kyna Player의 **듀얼 자막 시스템**을 통해 외국어 학습 및 이중 언어 동시 시청이 가능합니다.

---

## 📑 자막 트랙 선택 및 전환

- **자막 드로어**
  <kbd>Alt</kbd> + <kbd>S</kbd>로 엽니다.
- **우클릭 메뉴**
  화면 우클릭 → **자막** → **자막 트랙**.
- **순환 단축키**
  <kbd>V</kbd> 키를 누를 때마다 사용 가능한 트랙과 "자막 끄기"가 순환 전환됩니다.

---

## 👥 듀얼 자막 시스템 (동시 표시)

기본 자막과 보조 자막을 화면에 동시에 표시할 수 있습니다:
- **기본 자막**
  모국어 (한국어 등 큰 글씨로 표시).
- **보조 자막**
  원어 (영어/일본어 등 작은 글씨로 상/하단 배치).
- **독립 스타일**
  기본과 보조 자막의 폰트 크기, 수직 오프셋, 색상을 독립 설정하여 겹침을 방지합니다.

---

## 🎯 선호 언어 자동 선택

**설정 → 자막 기본값**에서 설정:
- **1순위 언어 코드**
  예: `ko, kor, 한국어`
- **2순위 언어 코드**
  예: `en, eng, 영어`
- 새 영상을 열었을 때 일치하는 자막 트랙이 자동으로 활성화됩니다.

---

## 📦 지원 자막 포맷

| 포맷 | 특징 | Kyna Player 지원 |
| :--- | :--- | :--- |
| **ASS / SSA** | 복잡한 애니메이션, 스타일, 위치 지정 지원 | libass 기반 완전한 하드웨어 렌더링 |
| **SRT** | 일반 텍스트 표준 포맷 | 폰트 및 스타일 자유 커스텀 지원 |
| **VTT** | 웹 스트리밍 표준 포맷 | 완벽 지원 |
| **PGS / SUP** | 블루레이 비트맵 그래픽 자막 | 무손실 비트맵 합성 렌더링 지원 |
