# 외부 자막 로드

다운로드한 외부 자막 파일을 손쉽게 추가하거나 자동으로 연결할 수 있습니다.

---

## 📥 외부 자막 로드 방법

1. **드래그 앤 드롭**: `.srt`, `.ass`, `.vtt`, `.sub` 파일을 재생 중인 화면에 직접 드래그합니다.
2. **파일 대화상자**: <kbd>Ctrl</kbd> + <kbd>L</kbd> 키를 눌러 자막 파일을 선택합니다.
3. **자동 로드**: 비디오와 같은 폴더에 있는 `[파일명].*.srt` 자막을 자동으로 탐색하여 로드합니다.
