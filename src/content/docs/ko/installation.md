# 📦 설치 및 시스템 요구사항

## 💻 시스템 요구 사양

| 항목 | 최소 사양 | 권장 사양 |
| :--- | :--- | :--- |
| **운영체제 (OS)** | Windows 10 (64-bit) 1909+ | Windows 11 (22H2+) |
| **프로세서 (CPU)** | Intel Core i3 / AMD Ryzen 3 | Intel Core i5 / AMD Ryzen 5 이상 |
| **그래픽 (GPU)** | Direct3D 11 하드웨어 디코딩 지원 | DX12 / HEVC / AV1 / VP9 가속 지원 |
| **메모리 (RAM)** | 4 GB | 8 GB 이상 |

---

## 🚀 설치 및 업데이트

1. **설치 프로그램 다운로드**
   [GitHub Releases](https://github.com/fynx-dev/kyna-release/releases/latest)에서 `Kyna-Player-vX.Y.Z-windows-x64.exe`를 다운로드합니다.
2. **설치 마법사 실행**
   설치 프로그램을 실행하고 화면의 안내에 따라 설치를 완료합니다.
3. **업데이트**
   플레이어를 종료한 후 최신 설치 프로그램을 실행하여 덮어쓰기 설치합니다. 기존 설정과 다운로드한 AI 모델은 그대로 유지됩니다.

---

## 🗄️ 앱 데이터 및 로그

설치 버전의 사용자 데이터는 `%LOCALAPPDATA%\Kyna\`에 저장됩니다. 실행 파일 옆에 `data` 폴더가 있는 포터블 버전은 해당 폴더를 사용합니다. 로그는 `logs\`에 저장되며, 크래시 덤프는 저장을 선택한 경우에만 `dumps\`에 생성됩니다.

---

## 🛠️ 시작 시 충돌하거나 바로 종료되는 경우

1. **오류를 기록하세요.** 발생 시각과 표시된 오류 코드를 적어 두세요. 필수 구성 요소가 없다는 메시지가 나오면 [공식 설치 프로그램](https://github.com/fynx-dev/kyna-release/releases/latest)으로 다시 설치하세요. 필요한 MSVC 런타임이 포함되어 있으므로 제삼자 사이트에서 개별 DLL을 다운로드하지 마세요.
2. **로그를 확인하세요.** 파일 탐색기에서 `%LOCALAPPDATA%\Kyna\logs`를 열고 `kyna-launcher.log` 및 충돌 시각에 가까운 최신 `kyna-player-*.log`를 확인하세요. 포터블 버전은 실행 파일 옆의 `data\logs`도 확인하세요.
3. **필요할 때만 덤프를 저장하세요.** 충돌 창에서 저장을 선택하면 로컬 파일이 생성되고 파일 탐색기에서 해당 파일을 보여 줍니다. 덤프에는 개인 정보가 포함된 메모리 데이터가 있을 수 있으며 자동으로 업로드되지 않습니다. 프로그램 시작 전의 일부 오류에서는 덤프를 만들 수 없습니다. 공개 Issue에 첨부하지 마세요.
4. **Windows 이벤트를 확인하세요.** **Win+R**에서 `eventvwr.msc`를 실행하고 **Windows 로그 → 응용 프로그램**에서 해당 시각의 오류를 찾으세요. **오류가 발생한 모듈 이름**과 **예외 코드**를 기록하세요.

[버그를 신고할 때](https://github.com/fynx-dev/kyna-release/issues/new?template=bug.yml) 플레이어와 Windows 버전, 재현 단계, 충돌 시각, 오류 코드 및 관련 로그를 함께 알려 주세요. 일반 로그에는 마스킹 후에도 개인 경로나 URL이 남아 있을 수 있으므로 공유 전에 확인하세요. 덤프는 내용과 개인정보 위험을 검토한 뒤 비공개 경로로만 공유하세요.
