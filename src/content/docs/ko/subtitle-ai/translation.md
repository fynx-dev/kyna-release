# LLM 자막 번역

기존의 기계적인 번역과 달리, Kyna Player는 **슬라이딩 컨텍스트 윈도우**를 사용하여 앞뒤 대화 흐름을 LLM에 전달함으로써 자연스럽고 매끄러운 번역을 완성합니다.

---

## 🔌 지원 번역 엔진

| 엔진 | 모델 예시 | 특징 |
| :--- | :--- | :--- |
| **DeepSeek** *(추천)* | `deepseek-chat`, `deepseek-reasoner` | 압도적인 가성비, 자연스러운 한국어 표현 |
| **OpenAI** | `gpt-4o`, `gpt-4o-mini` | 강력한 다국어 이해력 및 안정성 |
| **Anthropic Claude** | `claude-3-5-sonnet` | 높은 문학적 대화 뉘앙스 표현 |
| **Ollama (로컬)** | `qwen2.5`, `llama3.1`, `gemma2` | 100% 오프라인, 무료, 완전한 프라이버시 |
| **커스텀 API** | OpenAI 호환 엔드포인트 | 프록시 및 사내 API 게이트웨이 |

---

## 💬 이중 언어 자막 레이아웃

- **상/하 2개 국어 표시**
  상단에 번역(한국어), 하단에 원문(영어/일본어) 배치.
- **번역문만 표시**
  영상에 온전히 집중하는 깔끔한 자막.
- **파일 내보내기**
  `.srt` 또는 `.ass` 포맷으로 저장하여 타 기기에서도 사용 가능.
