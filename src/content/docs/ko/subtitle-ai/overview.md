# AI 자막 기능 개요

자막이 없는 해외 미디어, 외국어 강의 영상, 실시간 스트리밍 시청 시 Kyna Player의 **AI 자막 연구실**을 활용할 수 있습니다.

---

## ⚡ 핵심 AI 파이프라인

```
+------------------+     +--------------------+     +--------------------+     +------------------+
| 🔊 오디오 추출   | ──> | 🎙️ 로컬 Whisper    | ──> | 🌐 LLM 문맥 번역   | ──> | 💬 실시간        |
|  (FFmpeg Demux)  |     | (100% 오프라인/보안) |     | (자연스러운 표현)   |     |    이중 언어 자막|
+------------------+     +--------------------+     +--------------------+     +------------------+
```

---

## 🌟 주요 강점

1. **🔒 100% 로컬 오프라인 처리**: Whisper 음성 인식은 사용자 PC의 GPU(CUDA / DirectML / Vulkan) 또는 CPU에서 구동됩니다. 외부 서버로 오디오가 전송되지 않습니다.
2. **🧠 문맥을 고려한 고품질 번역**: DeepSeek, OpenAI GPT-4o, Claude, 로컬 Ollama와 연동하여 단순 직역이 아닌 자연스러운 번역 자막을 생성합니다.
3. **⚡ 자동 VAD 무음 제거**: Silero VAD를 통해 배경음악과 소음을 걸러내고 대화 구간별로 타임스탬프를 정밀하게 분할합니다.
