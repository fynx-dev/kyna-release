# AI 모델 및 가속 설정

**설정 → AI 모델 관리**에서 모델 다운로드 및 연산 백엔드를 설정할 수 있습니다.

---

## 📥 모델 다운로드 및 보관

- **원클릭 다운로드**
  SHA-256 자동 검증과 함께 안전하게 다운로드.
- **저장 디렉터리**
  `%APPDATA%\KynaPlayer\models\`
- **수동 추가**
  인터넷이 연결되지 않은 환경에서도 `ggml-*.bin` 파일을 models 폴더에 넣어 즉시 사용 가능.

---

## ⚡ 하드웨어 가속 백엔드

| 백엔드 | 대상 하드웨어 | 가속 비율 |
| :--- | :--- | :--- |
| **NVIDIA CUDA** *(추천)* | GeForce / RTX 시리즈 GPU | 🚀 초고속 (~20~30배) |
| **DirectML** | AMD Radeon / Intel Arc / 내장 GPU | ⚡ 고속 (~8~15배) |
| **Vulkan Compute** | 크로스 플랫폼 GPU | ⚡ 양호 (~8~12배) |
| **CPU AVX2 / OpenVINO** | 최신 멀티코어 CPU | 🔄 표준 (~2~4배) |

---

## 🧹 스마트 VRAM 자동 회수

- **지연 로딩**
  전사 작업 시작 시에만 VRAM에 모델을 로드.
- **자동 메모리 회수**
  작업 완료 후 5분간 미사용 시 VRAM을 자동 반환하여 4K 영상 재생 및 게임 성능을 보장합니다.
