# 로컬 음성 전사

Kyna Player는 고성능 **Whisper 오프라인 음성 인식 엔진**을 내장하여 오디오 트랙에서 타임스탬프 자막(`.srt` / `.vtt`)을 직접 추출합니다.

---

## 🛠️ 설정 파라미터

사이드바 **AI 연구실 → 음성 전사**:
- **입력 언어**
  자동 감지 또는 언어 코드(`ko`, `en`, `ja` 등)를 지정하여 정확도 향상.
- **오디오 트랙 선택**
  다중 더빙 트랙 중 대상 음성 지정 가능.
- **Silero VAD**
  무음 구간 및 폭발음, BGM을 자동 필터링하여 AI 환각 텍스트 방지.
