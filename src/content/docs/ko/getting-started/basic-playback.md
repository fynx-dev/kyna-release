# 기본 조작 및 키

Kyna Player는 직관적인 키보드 단축키와 마우스 제스처를 지원합니다.

---

## 🎮 필수 재생 제어

| 동작 | 기본 단축키 | 마우스 조작 | 설명 |
| :--- | :--- | :--- | :--- |
| **재생 / 일시정지** | <kbd>Space</kbd> | 화면 중앙 클릭 | 재생 상태 전환 |
| **정지** | <kbd>S</kbd> / <kbd>Ctrl+S</kbd> | 제어바 정지 버튼 | 디코딩 중지 및 시작 위치로 리셋 |
| **전체화면** | <kbd>Enter</kbd> / <kbd>F11</kbd> | 화면 더블 클릭 | 전체화면 모드 전환 |
| **프레임 전진 (한 프레임 앞으로)** | <kbd>.</kbd> / <kbd>E</kbd> | 프레임 전진 버튼 | 정확히 1프레임 앞으로 이동 |
| **프레임 후진 (한 프레임 뒤로)** | <kbd>,</kbd> | 프레임 후진 버튼 | 정확히 1프레임 뒤로 이동 |
| **볼륨 증가 / 감소** | <kbd>↑</kbd> / <kbd>↓</kbd> | 휠 상/하 스크롤 | 볼륨을 ±5% 단위로 조절 |
| **음소거 전환** | <kbd>M</kbd> | 스피커 아이콘 클릭 | 음소거 켜기 / 끄기 |
| **재생 속도 조절** | <kbd>]</kbd> / <kbd>[</kbd> | 배속 메뉴 | 배속을 ±0.1x 단위로 조절 |
| **정속도 리셋 (1.0x)** | <kbd>Backspace</kbd> / <kbd>Z</kbd> | 배속 메뉴 (1.0x) | 정상 속도로 즉시 복귀 |

---

## ⏩ 타임라인 탐색 (Seeking)

- **짧은 이동 (±5초)**
  <kbd>→</kbd> / <kbd>←</kbd>
- **중간 이동 (±30초)**
  <kbd>Ctrl</kbd> + <kbd>→</kbd> / <kbd>←</kbd>
- **긴 이동 (±60초)**
  <kbd>Shift</kbd> + <kbd>→</kbd> / <kbd>←</kbd>
- **백분율 점프 (0%~90%)**
  숫자 키 <kbd>0</kbd> ~ <kbd>9</kbd>
