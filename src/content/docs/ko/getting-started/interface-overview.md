# 인터페이스

Kyna Player는 영상에 온전히 집중할 수 있도록 **프레임리스 몰입형 디자인**을 채택했습니다. 직관적인 하단 제어바와 우측 사이드 패널을 통해 모든 기능을 빠르게 조작할 수 있습니다.

---

## 📐 레이아웃 구성

![인터페이스 개요](/assets/images/docs/getting-started/openfile-playlist-settings.png)

Kyna Player의 화면은 4개의 핵심 영역으로 구성됩니다:

```
+-------------------------------------------------------------+
| 🏷️ 상단 타이틀바 (창 제어 / 항상 위에 고정 / 미디어 제목)      |
+-------------------------------------------------------------+
|                                                             |
|                                            +--------------+ |
|                                            |              | |
|                    📺 메인 뷰포트            |  📑 사이드   | |
|                 (마우스 제스처 / 화면 조정)   |    드로어    | |
|                                            |              | |
|                                            +--------------+ |
+-------------------------------------------------------------+
| 🎛️ 플로팅 제어바 (타임라인 / 재생 제어 / 볼륨 / 도구 허브)   |
+-------------------------------------------------------------+
```

---

## 1. 🏷️ 상단 타이틀바

마우스를 창 상단으로 가져가면 나타납니다 (전체화면 시 자동 숨김):
- **📌 항상 위에 고정**
  플레이어를 다른 창보다 항상 앞에 표시합니다.
- **🎬 미디어 제목**
  현재 재생 중인 파일명을 표시합니다.
- **⚙️ 창 제어**
  최소화, 최대화 / 이전 크기 복원, 닫기.

---

## 2. 📺 메인 비디오 뷰포트

GPU 하드웨어 가속 렌더링 영역으로, 편리한 마우스 제스처를 지원합니다:

| 동작 | 실행 결과 |
| :--- | :--- |
| **클릭** | 재생 / 일시정지 전환 (설정 가능) |
| **더블 클릭** | 전체화면 모드 전환 |
| **마우스 휠** | 볼륨 조절 (±5% 단위) |
| **드래그 탐색** | 화면 중앙에 타임스탬프 및 미리보기 HUD 표시 |
| **드래그 앤 드롭** | 파일, 폴더, 자막 파일을 직접 화면에 드롭하여 로드 |
| **우클릭** | 전체 컨텍스트 메뉴 표시 (트랙, 필터, 설정 등) |

---

## 3. 🎛️ 플로팅 제어바

자주 사용하는 핵심 재생 기능이 모여 있습니다:
- **인터랙티브 타임라인**
  프로그레스 바 위로 마우스를 올리면 키프레임 썸네일 미리보기가 표시됩니다.
- **핵심 재생 버튼**
  이전/다음 (<kbd>PageUp</kbd>/<kbd>PageDown</kbd>), 재생/일시정지 (<kbd>Space</kbd>), 정지 (<kbd>S</kbd>), 프레임 단위 이동 (<kbd>.</kbd>).
- **볼륨 및 증폭**
  최대 200% 소프트웨어 음량 증폭을 지원하는 부드러운 슬라이더.
- **배속 및 반복 모드**
  0.5x ~ 2.0x 배속 전환 및 반복 모드 (전체 반복, 한 곡 반복, 셔플, 순차 재생).

---

## 4. 📑 사이드 드로어 패널

제어바 우측 아이콘이나 단축키로 슬라이드 드로어를 열 수 있습니다:

| 패널 이름 | 설명 | 단축키 |
| :--- | :--- | :--- |
| 📑 **재생목록** | 재생 대기열 관리, 파일 검색, 폴더 일괄 추가 | `F3` / `Alt+P` |
| 💬 **트랙 및 자막** | 오디오/자막 트랙 선택, 듀얼 자막, 스타일 커스텀 | `Alt+S` |
| 🤖 **AI 연구실** | Whisper 음성 전사, 대형 언어 모델 번역 | `Alt+A` |
| ✨ **화질 향상** | Anime4K, DLSS 5, 셰이더 필터, 색상 조정 | `Alt+V` |
| ⚙️ **설정** | 하드웨어 디코딩, 파일 연결, 다국어 전환 | `F2` / `Ctrl+,` |
