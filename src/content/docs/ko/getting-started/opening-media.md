# 미디어 열기

**Kyna Player**는 다양한 미디어 로드 방식을 지원합니다. 로컬 단일 파일, 시리즈 폴더 전체, 표준 M3U 목록, 실시간 스트리밍 URL까지 빠르고 간편하게 재생할 수 있습니다.

---

## 📂 1. 로컬 미디어 파일 열기

### 빠른 접근
- **단축키**
  <kbd>O</kbd> 키를 눌러 Windows 파일 선택 창을 엽니다.
- **화면 버튼**
  상단 메뉴 또는 제어바의 **파일 열기** 버튼을 클릭합니다.
- **지원 포맷**
  MP4, MKV, AVI, MOV, WEBM, FLV, WMV, TS, M2TS, M4V, RMVB, 3GP, VOB 등 주요 포맷 지원.

![파일 열기 메뉴](/assets/images/docs/getting-started/openfile-menu.png)

### 재생목록 추가 동작 설정
**설정 → 재생목록**에서 기본 동작을 선택할 수 있습니다:
- 🔄 **대체 후 재생** (기본값)
  현재 대기열을 비우고 선택한 파일을 즉시 재생합니다.
- ➕ **추가 후 재생**
  기존 대기열을 유지한 채 새 파일을 목록 끝에 추가하고 재생합니다.

![재생목록 설정](/assets/images/docs/getting-started/openfile-playlist-settings.png)

## 🖱️ 2. 파일 및 폴더 드래그 앤 드롭

### 파일 드롭
Windows 탐색기에서 동영상 또는 오디오 파일을 Kyna Player 창으로 직접 드래그합니다.

### 폴더 드롭 (스마트 일괄 스캔)
시리즈 폴더나 앨범 폴더를 드래그하면 **폴더 가져오기** 대화상자가 표시됩니다:
- 🔍 **재귀 스캔**
  "하위 폴더 포함"을 선택하여 모든 하위 디렉터리의 미디어를 탐색합니다.
- 📊 **실시간 카운터**
  스캔 진행률과 발견된 미디어 파일 수를 표시합니다.
- ⚡ **자연어 정렬**
  에피소드 번호 순서(EP01, EP02 ... EP10)로 올바르게 정렬됩니다.

![드래그 앤 드롭 폴더 스캔](/assets/images/docs/getting-started/drag-files-and-folder.png)

## 🌐 3. 네트워크 URL 스트리밍

온라인 스트리밍 및 라이브 방송 URL을 직접 재생할 수 있습니다:
- **URL 열기 대화상자**
  <kbd>Ctrl</kbd> + <kbd>U</kbd> 키를 누릅니다.
- **지원 프로토콜**
  HTTP / HTTPS 직링크, HLS (`.m3u8`), RTMP, RTSP, WebDAV.

![URL 열기 대화상자](/assets/images/docs/getting-started/open-url-dialog.png)
