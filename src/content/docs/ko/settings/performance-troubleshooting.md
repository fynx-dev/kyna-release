# 성능 최적화 및 해결

재생 중 버벅임이나 화면 이상이 발생했을 때의 해결 단계입니다:

---

## 🛠️ 주요 문제 및 해결책

### 1. 📺 4K/8K 재생 시 프레임 드롭 또는 끊김
- **GPU 할당 (듀얼 GPU 노트북)**
  Windows "설정 → 디스플레이 → 그래픽"에서 Kyna Player에 **"고성능 (NVIDIA / AMD 외장 GPU)"**을 할당하십시오.
- **하드웨어 가속**
  비디오 설정에서 **"Direct3D 11 (D3D11VA)"**이 켜져 있는지 확인하십시오.
- **셰이더 부하**
  Anime4K 등의 고사양 필터를 일시적으로 끄거나 *Mode Fast*로 낮추십시오.

### 2. 🟢 화면이 검거나 녹색으로 나오고 소리만 나오는 경우
- **해결책**
  화면 우클릭 → **비디오** → **"소프트웨어 디코딩 (CPU)"**으로 전환하고, 그래픽 드라이버를 최신 정식 버전으로 업데이트하십시오.

### 3. 🌈 SDR 모니터에서 HDR 영상 색감이 물빠진 듯 뿌옇게 나오는 경우
- **해결책**
  비디오 설정에서 **"SDR 톤 매핑"**을 활성화하고 알고리즘을 `Reinhard` 또는 `Mobius`로 지정하십시오.
