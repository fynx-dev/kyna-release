# 설정 센터

하드웨어 사양과 취향에 맞추어 Kyna Player의 모든 동작을 커스터마이징할 수 있습니다.

---

## 🚪 설정 창 열기

- **단축키**
  <kbd>F2</kbd> 또는 <kbd>Ctrl</kbd> + <kbd>,</kbd>
- **화면 버튼**
  제어바 우측 하단 `⚙️ 설정` 아이콘 클릭.

---

## 📑 설정 카테고리

- 🏠 **일반 (General)**
  인터페이스 언어, 다중 실행 방지, AppData 폴더 바로가기.
- ⏯️ **재생 (Playback)**
  기본 배속, 다음 화 자동 재생, 탐색 이동 단위.
- 📺 **비디오 (Video)**
  Direct3D 11/12 GPU 가속, HDR 톤 매핑, Anime4K 프리셋.
- 🔊 **오디오 (Audio)**
  출력 장치, 서라운드 다운믹싱, 야간 모드(DRC).
- 💬 **자막 (Subtitles)**
  기본 선호 언어, 폰트, 테두리 외곽선, 온라인 자막 제공자.
- 🤖 **AI 연구실 (AI Lab)**
  Whisper 모델, LLM API 키, VRAM 자동 반환 규칙.
- ⌨️ **단축키 (Hotkeys)**
  키보드 및 마우스 조작 바인딩.
- 🔗 **파일 연결 (Files)**
  동영상 파일 기본 앱 등록 및 Windows 우클릭 메뉴 통합.
