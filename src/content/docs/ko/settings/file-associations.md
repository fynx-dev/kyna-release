# 파일 연결 설정

동영상 및 음악 파일을 더블 클릭했을 때 Kyna Player로 즉시 열리도록 설정합니다.

---

## ⚡ 원클릭 연결

**설정 → 파일 연결**:
- **"모든 동영상 포맷 연결"**을 클릭하여 MP4, MKV, AVI, MOV, TS, WEBM 등을 일괄 등록.
- Windows의 "연결 프로그램" 메뉴에 **"Kyna Player"**로 깔끔하게 표시됩니다.
