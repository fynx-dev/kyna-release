# 비디오 출력 및 화면

Kyna Player는 Direct3D 11/12 기반의 고성능 렌더링 파이프라인을 탑재하여 GPU 디코딩 성능을 극대화하면서 화면 비율 조정, 색상 보정, HDR 출력을 완벽하게 지원합니다.

---

## 🚀 비디오 출력 및 하드웨어 가속

**설정 → 비디오 및 렌더링**에서 적합한 렌더러를 선택할 수 있습니다:

| 출력 모드 | 특징 및 장점 | 권장 환경 |
| :--- | :--- | :--- |
| **Direct3D 11 (D3D11)** *(권장)* | 높은 호환성과 초저지연. GPU 제로카피 직접 출력 지원. | Windows 10/11 일반 외장/내장 GPU |
| **Direct3D 12 (D3D12)** | 최신 GPU 연산 파이프라인에 최적화된 저수준 렌더링. | 최신 외장 GPU (RTX / RX 시리즈) |
| **소프트웨어 디코딩 (CPU)** | 비표준 레거시 코덱을 위한 안전한 폴백. | 문제 해결 및 디버깅용 |

---

## 📐 화면 비율 및 스케일링 모드

<kbd>A</kbd> 키 또는 우클릭 메뉴의 **화면 비율**에서 변경:
- **비율 유지 (Fit)** *(기본값)*: 원본 비율을 유지하며 레터박스 추가.
- **창에 맞추기 (Stretch)**
  창 크기에 맞춰 강제로 늘려 채움.
- **잘라내어 채우기 (Crop)**
  비율을 유지하면서 여백 없이 확대.
- **고정 비율**
  `16:9`, `4:3`, `21:9` (울트라와이드), `1:1`.

---

## 🎚️ 실시간 색상 보정

사이드바 **화질 패널**에서 실시간 조절:
- **밝기 / 대비**
  -50 ~ +50
- **채도 / 색조**
  -50 ~ +50
- **감마**
  0.5 ~ 2.0
- **원클릭 초기화**
  기본 프로필로 즉시 복귀.

---

## 🔄 화면 회전 및 반전

- **시계 방향 90° 회전**
  <kbd>Alt</kbd> + <kbd>R</kbd>
- **좌우 거울 반전 (Mirror)**
  <kbd>Alt</kbd> + <kbd>H</kbd> (댄스 안무 연습에 최적)
- **상하 반전**
  <kbd>Alt</kbd> + <kbd>V</kbd>

---

## 🌈 HDR 및 톤 매핑

4K HDR10, HLG, Dolby Vision 영상 재생 시:
- **HDR 패스스루**
  HDR 지원 디스플레이에 10-bit BT.2020 신호를 다이렉트 출력.
- **SDR 톤 매핑**
  일반 SDR 모니터에서도 Reinhard / Mobius 알고리즘으로 하이라이트 손실 없이 화사하고 풍부한 색상 표현.
