# Anime4K 초해상도

Anime4K는 2D 애니메이션 콘텐츠에 특화된 실시간 화질 향상 알고리즘입니다. 선명한 윤곽선을 복원하고 노이즈를 제거하여 4K 급 고화질로 업스케일링합니다.

---

## 🚀 Anime4K 활성화

사이드바 **화질 패널** 또는 <kbd>Alt</kbd> + <kbd>V</kbd>로 엽니다:
- **Anime4K Mode A (Fast)**
  내장 그래픽 및 노트북에 적합한 가볍고 빠른 프리셋.
- **Anime4K Mode B (HQ)**
  720p 저해상도 애니메이션을 위한 고정밀 윤곽선 복원.
- **Anime4K Mode C+A (Ultra)**
  윤곽선 강화와 블러 제거가 결합된 최고 품질 모드.

---

## 🔀 실시간 비교 뷰

- **좌우 분할 비교**
  슬라이더 구분선을 좌우로 드래그하여 원본과 개선된 화질을 실시간 비교.
- **차이 히트맵**
  알고리즘에 의해 복원된 고주파 디테일을 시각화.

---

## ⏱️ 동적 성능 예산

GPU 처리 시간이 16.6ms(60 FPS 기준)를 초과할 경우 프레임 드롭을 방지하기 위해 자동으로 경량 셰이더로 전환됩니다.
