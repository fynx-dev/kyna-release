# 반복 및 재생 모드

드라마 연속 시청, 뮤직비디오 무한 반복, 음악 라이브러리 랜덤 재생 등 다양한 재생 방식을 지원합니다.

---

## 🔀 4가지 핵심 재생 모드

제어바의 반복 아이콘을 클릭하거나 <kbd>Ctrl</kbd> + <kbd>R</kbd>을 눌러 순환 전환합니다:

| 아이콘 | 모드 | 설명 | 추천 상황 |
| :---: | :--- | :--- | :--- |
| 🔁 | **전체 반복** | 목록의 마지막 항목까지 재생 후 처음으로 돌아가 반복. | 드라마/애니 연속 시청 |
| 🔂 | **한 곡 반복** | 현재 파일을 무한 반복 재생. | 강의/춤 연습 영상 |
| 🔀 | **셔플** | 목록 내의 곡을 중복 없이 무작위 순서로 재생. | 음악 라이브러리 |
| ➡️ | **순차 재생** | 현재 항목부터 목록 끝까지 재생 후 자동 정지. | 영화 감상, 수면 타이머 |

---

## ⏭️ 이전 / 다음 이동

- **다음 파일**
  <kbd>PageDown</kbd> 또는 <kbd>N</kbd>
- **이전 파일**
  <kbd>PageUp</kbd> 또는 <kbd>P</kbd>

---

## 📺 스마트 다음 에피소드 자동 재생

시리즈 애니메이션이나 드라마를 불러왔을 때:
1. **자연어 정렬**: 에피소드가 올바른 순서(`EP01, EP02 ... EP10`)로 자동 배열됩니다.
2. **원활한 프리로드**: 현재 파일 재생 종료 직전에 다음 에피소드를 백그라운드 프리로드합니다.
3. **이어보기 기억**: 각 에피소드의 마지막 시청 위치를 자동으로 저장합니다.
