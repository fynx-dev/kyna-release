# 재생목록 개요

대량의 동영상 관리, 드라마 몰아보기, 음악 라이브러리 연속 재생을 쾌적하게 지원합니다.

---

## 🚪 재생목록 열기

- **단축키**
  <kbd>F3</kbd> 또는 <kbd>Alt</kbd> + <kbd>P</kbd>
- **제어바**
  우측 하단 `📑 재생목록` 아이콘 클릭.

---

## ⚡ 주요 기능

- **다중 파일/폴더 추가**
  파일 및 폴더를 목록에 직접 드래그 앤 드롭.
- **드래그로 순서 변경**
  항목을 위아래로 끌어다 놓아 직관적으로 재생 순서 변경.
- **최근 재생 기록**
  지난번 중단된 위치 자동 기억.
- **M3U8 지원**
  UTF-8 인코딩 지원 범용 재생목록 가져오기/내보내기.
