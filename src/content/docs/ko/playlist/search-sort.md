# 검색, 정렬 및 정리

수백 개의 파일 속에서도 원하는 미디어를 즉시 찾아 올바른 순서로 재생할 수 있습니다.

---

## ⚡ 실시간 검색

- 검색창에 키워드를 입력하면 실시간으로 해당 항목만 필터링됩니다.
- <kbd>Esc</kbd> 키를 누르면 검색이 초기화되고 전체 목록으로 돌아옵니다.

---

## 🔢 자연어 정렬 (Natural Sort)

기존 ASCII 정렬에서 발생하는 `1, 10, 2` 순서 꼬임을 완벽 방지:
- 올바른 자연어 정렬: `제1화` → `제2화` → `제10화`.
- 파일명 순, 수정 날짜 순, 파일 크기 순, 무작위 셔플 지원.

---

## ✨ 파일명 깔끔 표시 (Clean Title)

**"파일명 정리하여 표시"**를 켜면:
- 릴리즈 그룹 태그(예: `[1080p][x265][AAC]`)를 자동으로 숨겨 깔끔한 회차 제목으로 보여줍니다.
