# 폴더 일괄 가져오기

애니메이션 전체 시즌이나 앨범 전체를 원클릭으로 등록할 수 있습니다.

---

## 🚀 가져오기 방법

1. **드래그 앤 드롭**: 하나 이상의 폴더를 플레이어 창으로 직접 드래그.
2. **메뉴에서 열기**: **파일 → 폴더 열기...** (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd>) 선택.

---

## 🔍 재귀 스캔 및 필터링

- **불필요한 파일 자동 제외**
  동영상 및 오디오 파일만 자동 등록하고 이미지, `.nfo`, `.torrent`, 로그 파일은 건너뜁니다.
- **하위 폴더 스캔**
  `Season 1/`, `Season 2/` 등의 계층 구조도 자동 탐색하여 취합합니다.
- **외부 자막 자동 감지**
  동일한 이름의 `.srt` / `.ass` 자막이 존재하면 자동으로 연결됩니다.
