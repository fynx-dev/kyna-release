# 최근 기록 및 파일

과거 시청 기록을 확인하고 로컬 파일을 플레이어 내에서 편리하게 관리할 수 있습니다.

---

## 📜 최근 재생 기록

- **이어보기 표시**
  마지막 중단 지점을 표시 (예: `45:12까지 시청 (68%)`).
- **원클릭 이어보기**
  더블 클릭하여 중단했던 시점부터 즉시 재생.
- **기록 초기화**
  "기록 지우기"를 클릭하여 모든 시청 기록을 한 번에 정리.

---

## 🗂️ 컨텍스트 메뉴 파일 조작

목록 항목 우클릭:
- **파일 위치 열기**
  <kbd>Ctrl</kbd> + <kbd>E</kbd>로 탐색기 실행.
- **목록에서 제거**
  <kbd>Delete</kbd> (디스크의 실제 파일은 유지).
- **휴지통으로 이동**
  <kbd>Shift</kbd> + <kbd>Delete</kbd> (다 본 파일을 Windows 휴지통으로 직접 삭제).
- **파일 경로 복사**
  <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd>
