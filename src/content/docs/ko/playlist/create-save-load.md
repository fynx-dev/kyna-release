# 재생목록 관리

좋아하는 영상과 음악 큐를 표준 재생목록 파일로 저장하고 관리할 수 있습니다.

---

## ➕ 재생목록 생성 및 관리

1. **새 목록**: 재생목록 상단의 `➕ 새로 만들기`를 클릭하여 빈 대기열 생성.
2. **파일 추가**: "파일 추가" 클릭 또는 탐색기에서 드래그 앤 드롭.
3. **순서 조절**: 항목을 드래그하여 재생 순서 조정.

---

## 💾 저장 및 내보내기 (M3U8)

- **재생목록 저장**
  **"💾 저장 / 다른 이름으로 저장"** 클릭.
- **M3U8 (UTF-8)** *(추천)*: 한글 및 특수문자가 포함된 파일명도 깨짐 없이 보존.
- **상대 경로 지원**
  외장 하드로 이동해도 재생목록이 그대로 정상 작동합니다.
