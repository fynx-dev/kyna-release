# Settings Center

Customize every aspect of Kyna Player to match your hardware configuration and viewing preferences.

---

## 🚪 Opening Settings

- **Hotkey**
  <kbd>F2</kbd> or <kbd>Ctrl</kbd> + <kbd>,</kbd>.
- **Access**
  Click the `⚙️ Settings` button in the control dock or select **Preferences** from the context menu.

---

## 📑 Settings Categories

- 🏠 **General**
  UI language, single-instance mode, AppData folder access.
- ⏯️ **Playback**
  Default speed, auto-play next, seek step sizes.
- 📺 **Video & Rendering**
  Direct3D 11/12 GPU acceleration, HDR tone mapping, Anime4K presets.
- 🔊 **Audio**
  Output device routing, multi-channel downmixing, Dynamic Range Compression.
- 💬 **Subtitles**
  Preferred languages, fonts, outline stroke, online subtitle providers.
- 🤖 **AI Lab**
  Whisper models, LLM API keys, VRAM auto-unload rules.
- ⌨️ **Hotkeys**
  Custom keyboard and mouse gesture bindings.
- 🔗 **File Associations**
  Register default video player extensions and Windows context menu entries.
