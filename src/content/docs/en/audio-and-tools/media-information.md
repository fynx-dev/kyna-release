# Media Info & Diagnostics

Inspect detailed container metadata and live hardware decoding status.

---

## 🔍 Opening Media Info

- **Hotkey**
  <kbd>Ctrl</kbd> + <kbd>I</kbd> or <kbd>Shift</kbd> + <kbd>I</kbd>.
- **Menu**
  Right-click → **Tools** → **Media Info**.

---

## 📊 Full Spectrum Diagnostics

- **Container Info**
  Format (`.mkv`, `.mp4`), size, bitrate.
- **Video Stream**
  Codec (`HEVC`, `AV1`, `H.264`), resolution (`3840x2160`), FPS, color space (`BT.2020 10-bit`), HDR standard (`HDR10`, `Dolby Vision`).
- **Audio & Subtitle Streams**
  Channel layout, sample rate, language tags.
- **Live Pipeline Stats**
  Active hardware decoder (`D3D11VA - NVIDIA NVDEC`), real-time bitrate graph, and frame drop counter.
