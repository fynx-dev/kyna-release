## Overview

**Kyna Player** is a modern media player built for Windows 10/11 featuring hardware-accelerated Dolby Vision decoding and HDR 10-bit to SDR real-time conversion.

Whether watching high bitrate 4K movies or local video collections, Kyna Player provides an immersive and fluid playback experience.

## Key Features

- **Dolby Vision & HDR Support**: Real-time hardware tone mapping for displays without native HDR.
- **Modern Glassmorphic UI**: Borderless mini player, glass navbar, and multi-language support.
- **Extensive Shortcuts**: Full keyboard navigation support.
